# LDAP Storage Mode & Edit Mode

**Two settings on an LDAP provider that decide (a) whether users are copied into
RHBK's database and (b) whether changes write back to LDAP.**

## Storage mode — the *Import Users* switch
- **Import ON** (default): RHBK imports and synchronizes a local copy of each
  LDAP user into its own database. Enables full querying/listing and lets other
  mappers/attributes attach locally.
- **Import OFF**: users are read from LDAP on demand, with no local copy. Lower
  storage footprint; some operations that depend on the local DB are limited.

## Edit mode
- `READ_ONLY` — RHBK never writes to LDAP; profile is immutable from RHBK's side.
- `WRITABLE` — profile/password changes propagate back into LDAP.
- `UNSYNCED` — changes are stored in RHBK's local DB only, **not** pushed to LDAP.

## Caveats
- `WRITABLE` requires the bind account to have write permission in the directory.
- `UNSYNCED` + Import ON means RHBK and LDAP can drift — the local copy diverges (inferred consequence of the UNSYNCED description, not stated as a drift warning in the source).
- Wording stable across RHBK 26.0–26.6 (`Chapter 4. Using external storage`).
