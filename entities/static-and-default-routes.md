# Static & Default Routes (IOS XE)

**User-defined routes that force traffic for a prefix along a chosen path, and the mechanisms that produce a gateway of last resort for everything else.**

## Static routes
`ip route prefix mask {next-hop-ip | interface [next-hop]} [distance] [name] [permanent | track n] [tag]`. **Default administrative distance = 1**; up to 6 parallel static paths. A static is removed when its outbound interface goes down or its next hop can't be resolved.

**Two traps:**
- A static pointing to an **interface** (not a next-hop IP) is treated as *connected* and is **advertised by RIP/EIGRP even without `redistribute static`** — losing its static nature.
- A **floating static** (distance raised above the protocol's, e.g. `… 110`) only wins when the dynamic route disappears — see [[cisco-administrative-distance]].

## Default routes / gateway of last resort
Three approaches with different scopes:
- `ip default-gateway` — used **only when IP routing is disabled** (host/boot mode).
- `ip default-network` — used when routing is enabled; flags a known network as the default candidate.
- `ip route 0.0.0.0 0.0.0.0 next-hop` — a static default.

**Propagation differs by protocol:** IGRP doesn't recognize a 0.0.0.0/0 static (use `ip default-network`); EIGRP propagates 0.0.0.0 only if the static is redistributed; **OSPF and IS-IS don't advertise or redistribute a 0.0.0.0/0 static — inject it with `default-information originate`.**
