# bootstrap-admin fails with "dns_query can not be null or empty"

**Symptom → cause → fix for creating a temporary admin when the Kubernetes Infinispan stack has no DNS query.**

## Body
**Symptom.** `kc.sh bootstrap-admin` fails with `ISPN000541` /
`java.lang.IllegalArgumentException: dns_query can not be null or empty`.

**Cause.** The transient server started for `bootstrap-admin` uses Infinispan's
Kubernetes cache stack, which requires the `jgroups.dns.query` property — absent
during the bootstrap run.

**Fix.** Switch to the **local** cache stack for the bootstrap run only:
```
KC_CACHE=local kc.sh bootstrap-admin
# or
kc.sh bootstrap-admin --cache=local
```
Confirm `KC-SERVICES0077: Created temporary admin user with username admin1` in
the logs, then revert the local cache setting and start normally.

Note: local cache may also log "Unable to start the management interface" /
"Address already in use", but the user is created **before** that server start,
so the bootstrap still succeeds.

Applies to RHBK 26.x using bootstrap-admin on the Infinispan Kubernetes stack.

## Contradictions / caveats
This is a bootstrap-only workaround — do not leave `KC_CACHE=local` set for the
clustered runtime (it disables distributed caching). See [[distributed-caches]].
