# `ingress` & reverse-proxy exposure

**How the Operator exposes RHBK: the built-in `spec.ingress` and the
`spec.proxy.headers` setting on the [[keycloak-cr]].**

## Built-in ingress

```yaml
spec:
  ingress:
    enabled: true        # default; set false to manage your own
    className: openshift-default
```

- On clusters with multiple default `IngressClass` instances, or OpenShift 4.12+,
  set `ingress.className`.
- With ingress enabled and `className: openshift-default`, you may leave
  `spec.hostname.hostname` unset; the Operator assigns a default route host
  (`ingress-namespace.appsDomain`).
- Disable with `ingress.enabled: false` and point your own ingress/Route at the
  `<cr-name>-service`. Example: on OpenShift, wildcard certs aren't allowed on
  passthrough Routes with HTTP/2, so disable the built-in ingress and create a
  `reencrypt` Route instead.
- For debugging: `oc port-forward service/<cr-name>-service 8443:8443`.

## Reverse-proxy headers

`spec.proxy.headers` controls which headers the server trusts:
`forwarded` | `xforwarded` | `forwarded|xforwarded`. If unset, the Operator falls
back to the legacy implicit `proxy=passthrough` (deprecation warnings; removed in a
future release). Ensure the Ingress sets/overwrites the matching `Forwarded` /
`X-Forwarded-*` headers, and use reencrypt or edge TLS termination — passthrough
TLS can't rewrite request headers. Misconfiguration leaves RHBK exposed.

## Admin-hostname interaction

If you set `hostname-admin` (or the deprecated `hostname-admin-url`), no ingress is
created for admin access even with ingress enabled — admin access via a separate
hostname is expected to carry its own access restrictions (not expressible in the
CR). The default ingress does not block admin endpoints, so consider not enabling
CR ingress at all when using a separate admin hostname.

## Contradictions / caveats

- The legacy `proxy=passthrough` fallback is slated for removal; set
  `proxy.headers` explicitly. Hostname behavior described here is the
  hostname-v2 model used across 26.x.
