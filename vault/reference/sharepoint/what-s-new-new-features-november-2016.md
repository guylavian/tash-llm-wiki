# New features in November 2016 PU for SharePoint Server 2016 (Feature Pack 1)

**APPLIES TO:** 2013 2016 2019 Subscription Edition SharePoint in Microsoft 365

For a list of updates and associated KB articles for SharePoint Server 2016, SharePoint 2013, and SharePoint 2010, see SharePoint Updates.

Summary of features

## Summary of features

The following table provides a summary of the new features and enhancements that are included in the November 2016 Public Update for SharePoint Server 2016 (Feature Pack 1) release.

| **Feature** | **Description** | **More info** |
| --- | --- | --- |
| **MinRole enhancements** | The MinRole feature in SharePoint Server 2016 now includes two new server roles and enhanced support for small farms. | For more info, see "Minrole enhancements" in Overview of MinRole Server Roles in SharePoint Server 2016. |
| **SharePoint Custom Tiles** | SharePoint admins can now add SharePoint and Microsoft 365 workloads as custom tiles in SharePoint app launcher. | For more info, see Custom Tiles in SharePoint Server. |
| **Hybrid Taxonomy** | Hybrid Taxonomy is a new solution that you can use to create and maintain a shared taxonomy between your SharePoint Server 2016 farm and your SharePoint in Microsoft 365 tenant. | For more info, see SharePoint Hybrid Taxonomy. |
| **Administrative Actions Logging** | The Administrative Actions Logging feature provides logging around common SharePoint administrative actions to aid SharePoint admins in troubleshooting changes to their farm. | For more info, see Using Administrative Actions logging in SharePoint Server 2016 topic. |
| **OneDrive API for SharePoint on-premises and Microsoft 365** | The OneDrive API provides a support for access to files located in SharePoint Server 2016 and in Microsoft 365. Use it to work with data stored in OneDrive and across SharePoint sites. | For more info, see OneDrive API. |
| **SharePoint Hybrid Auditing** | This new feature for SharePoint Server 2016 lets administrators view user activity logs in the Microsoft 365 admin center. 

Note: This feature is no longer available in SharePoint Server 2016 starting with the Security update for SharePoint Enterprise Server 2016: November 12, 2019. | For more info, see SharePoint Hybrid Auditing (Preview). |
| **OneDrive modern experience** | OneDrive user experience has been updated with new functionalities from Microsoft 365.  
 The OneDrive modern user experience requires an active Software Assurance contract at the time it is enabled. | For more info, see Configure the OneDrive modern user experience. |
