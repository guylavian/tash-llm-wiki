# pktmon status

# pktmon status



Query current Packet Monitor status.

## Syntax

```
pktmon status [--buffer-info]
```

### Parameters

| **Parameter** | **Description** |
| ------------- | --------------- |
| **-b, --buffer-info** | Display ETW buffer information. |
