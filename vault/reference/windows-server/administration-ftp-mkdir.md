# ftp mkdir

# ftp mkdir



Creates a directory on the remote computer.

## Syntax

```
mkdir <directory>
```

### Parameters

| Parameter | Description |
| --------- | ----------- |
| `<directory>` | Specifies the name of the new remote directory. |

### Examples

To create a directory called *dir1* on the remote computer, type:

```
mkdir dir1
```
