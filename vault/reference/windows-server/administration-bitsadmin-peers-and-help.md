# bitsadmin peers and help

# bitsadmin peers and help

Displays the command-line usage for the **/peers** switches.

## Syntax

```
bitsadmin /peers /help
```

## Examples

To display the command-line usage for the **/peers** switches:

```
bitsadmin /peers /help
```
