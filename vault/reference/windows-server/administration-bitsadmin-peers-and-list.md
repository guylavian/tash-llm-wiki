# bitsadmin peers and list

# bitsadmin peers and list

Applies to: Windows Server (All supported versions)

The `bitsadmin` command lists all peers when it's combined with the **peers** and **list** switches.

## Syntax

```CLI
bitsadmin /peers /list
```

## Examples

To list all peers:

```CLI
bitsadmin /peers /list
```
