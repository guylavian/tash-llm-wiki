# ftp delete

# ftp delete



Deletes files on remote computers.

## Syntax

```
delete <remotefile>
```

### Parameters

| Parameter | Description |
| --------- | ----------- |
| `<remotefile>` | Specifies the file to delete. |

### Examples

To delete the *test.txt* file on the remote computer, type:

```
delete test.txt
```
