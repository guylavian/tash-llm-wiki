# Support Policy for Cloud Database Usage on Application Services Products

Support Policy for Cloud Database Usage on Application Services Products
Updated -
Red Hat supports the use of cloud databases for products inside the Application Services portfolio, providing that the cloud database version and its connector are equivalent to a supported on-premise distribution of the database, as defined in the product Supported Configurations page.
Support from Red Hat is limited by the compatibility commitments and feature parity as defined by the cloud provider.
Red Hat Support might ask customers to replicate issues using a supported on-premise distribution of the database.
Red Hat Application Services products covered by this policy
This article applies to the components offered in the RHAF, Runtimes and Integrations bundles.
