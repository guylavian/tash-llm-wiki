# RHBK 26 Cannot parse the JSON error while searching for users in Admin console

RHBK 26 Cannot parse the JSON error while searching for users in Admin console
Environment
- Red Hat Build of Keycloak
- 26.0.x
Issue
- "Cannot parse the JSON" or "error unknown" while searching for users using pagination during LDAP sync on the Admin console. The error occurred specifically when searching for users with the first name "abc," but not for other names like "xyz." The issue impacted developers using the application.
Resolution
- To search using "spaces", you must search the value with double quotes. E.g:
https://host/auth/admin/realms/customrealm/users?firstName="XYZ jose" - Regarding searching for a "specific" user, you have the option to use the query param "exact=true", e.g:
https://hostname/auth/admin/realms/customrealm/users?firstName="XYZ jose"&exact=true
This is documented in the admin api
Root Cause
- LDAP query was failing due to a class cast exception. The issue was caused by a mismatch between the expected and actual data types in the LDAP query.
