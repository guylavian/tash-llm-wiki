# About Operator Lifecycle Manager v1

[id="olmv1-about"]
= About Operator Lifecycle Manager v1

{olm-first} has been included with OpenShift Container Platform 4 since its initial release. OpenShift Container Platform 4.18 includes components for a next-generation iteration of {olm} as a Generally Available (GA) feature, known during this phase as _{olmv1}_. This updated framework evolves many of the concepts that have been part of previous versions of {olm} and adds new capabilities.

Starting in OpenShift Container Platform 4.17, documentation for {olmv1} has been moved to the following new guide:
