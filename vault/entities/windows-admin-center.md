# Windows Admin Center

**Windows Admin Center (WAC, formerly "Project Honolulu") is a browser-based
remote-management tool for Windows Server running anywhere — physical, virtual,
on-premises, or in Azure — at no extra licensing cost.**

## Body

WAC installs on a Windows PC (v2, port 6600 for local access) or as a service on
Windows Server (port 443 for remote access); you must be a local administrator to
use it. It complements — rather than replaces — Server Manager, RSAT, System
Center, Intune, or Azure Stack.

**Managed connections** (servers, Windows PCs, clusters, Azure VMs) are added
one-at-a-time, bulk-imported from a `.txt`/`.csv` file, or discovered by searching
Active Directory (requires the WAC computer to be domain-joined). Connections can
be organized and filtered with **tags**.

**Authentication to managed nodes** defaults to **single sign-on** using the
signed-in user's Windows credentials; alternatives are specifying different
credentials per connection ("Manage as") or, if the environment already uses
**Local Administrator Password Solution (LAPS)**, authenticating with LAPS
credentials. WAC impersonates the "Manage as" account's security context to
perform remote management.

**Key scenarios:** simplified server management (a modernized Server Manager),
Azure hybrid integration, and streamlined **hyperconverged infrastructure**
management — creating/managing VMs, [[storage-spaces-direct]] volumes,
software-defined networking, and [[failover-cluster-quorum]] clusters. From
within any tool, you can view the exact **PowerShell script** each UI action runs
— a transparency feature for scripting/automation.

## Contradictions / caveats

WAC is licensed at no extra cost, but it's scoped to managing a **single server
or cluster at a time** — larger fleets are expected to layer System Center,
Intune, or Azure Arc on top rather than use WAC as the sole management plane
(extracted from the overview's "Related products" section).
