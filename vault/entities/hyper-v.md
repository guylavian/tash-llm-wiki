# Hyper-V

**Hyper-V is Microsoft's enterprise-grade type-1 hypervisor, built into Windows
Server and Windows, running directly on hardware for near-native VM performance
and isolation.**

## Body

Hyper-V is included with Windows Server and Windows — the Datacenter edition
grants unlimited Windows Server VM rights, so there's no separate hypervisor
license. It supports Windows, Linux, and FreeBSD guests.

Key composable features:
- **High availability** — pairs with [[failover-cluster-quorum]] and Cluster
  Shared Volumes for automatic VM failover and zero-downtime **live migration**;
  **shared-nothing live migration** moves VMs between hosts without shared storage.
- **Disaster recovery** — **Hyper-V Replica** asynchronously replicates VMs to a
  secondary site with a Recovery Point Objective as low as 30 seconds, without
  requiring SAN-level replication.
- **Storage flexibility** — local disks, [[storage-spaces-direct]] (hyperconverged),
  disaggregated Storage Spaces (JBOD pools), or traditional SAN over iSCSI/Fibre
  Channel with MPIO.
- **Security and isolation** — Generation 2 VMs add UEFI, Secure Boot, and vTPM
  2.0 (enabling in-guest BitLocker); **Shielded VMs** add BitLocker + Secure Boot +
  TPM attestation via a Host Guardian Service, protecting sensitive workloads even
  from a compromised host administrator.
- **Management** — Hyper-V Manager, PowerShell (including **PowerShell Direct**,
  which manages a VM without network connectivity), System Center Virtual Machine
  Manager, or [[windows-admin-center]] (including a dedicated "Virtualization
  Mode" for fabric-scale management distinct from general server management).

## Contradictions / caveats

Hyper-V's disaster-recovery story for a hyperconverged (Storage Spaces Direct)
cluster is deliberately narrower than for a traditional Hyper-V cluster: a stretch
scenario is **not supported** for hyperconverged deployments, so DR there relies on
Hyper-V Replica or [[storage-replica]] between two independent clusters rather than
one cluster spanning sites (inferred from the Storage Spaces Direct
disaster-recovery guidance, which is the authoritative source for that constraint).
