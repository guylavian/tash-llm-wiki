# SCCM Compliance Baselines

**A configuration baseline bundles configuration items (and optionally other baselines); once
deployed to a collection, devices in it download the baseline and assess compliance against it.**

## Body

### Create

A baseline can be built two ways: importing configuration data from a file (via the **Import
Configuration Data Wizard**), or using the **Create Configuration Baseline** dialog directly.
Baselines can reference either a specific configuration-item revision or always use the latest
revision. **There is no way to control the order in which the client evaluates the configuration
items in a baseline — evaluation order is non-deterministic.**

### Deploy

A baseline must be deployed — via the **Deploy Configuration Baselines** dialog (Assets and
Compliance > Compliance Settings > Configuration Baselines) — to one or more collections before
any client reports compliance against it; the dialog also sets the evaluation schedule and lets
you add/remove baselines from an existing deployment.

### Compliance and the shared-responsibility model

Configuration Manager's compliance features exist to help meet regulatory/industry requirements,
but under Microsoft's **shared responsibility model**, Microsoft ensures the product itself
complies with industry standards while the customer is responsible for implementing their own
data-protection/compliance strategy on top of it. Compliance also depends on adjacent services —
Microsoft Entra ID for identity/access, Microsoft Intune for enforcing device compliance and
Conditional Access policies.
