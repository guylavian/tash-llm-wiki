# Configure web content management solutions in SharePoint Server

**APPLIES TO:** 2013 2016 2019 Subscription Edition SharePoint in Microsoft 365

The articles that are listed in the following table describe how to set up cross-site publishing features in a SharePoint Server environment.

|  | **Content** | **Description** |
| --- | --- | --- |
|  | Configure cross-site publishing in SharePoint Server | Learn how to create site collections for cross-site publishing, activate the Cross-Site Collection Publishing feature, create and manage term sets for tagging content on authoring sites, create catalog content by using SharePoint lists, share a library or list as a catalog, and configure search settings for cross-site publishing. |
|  | Connect a publishing site to a catalog in SharePoint Server | Learn how to connect a publishing site to a library or list that is shared as a catalog. |
|  | Assign a category page and a catalog item page to a term in SharePoint Server | Learn how to assign a category page and a catalog item page to a term in term store management. |
|  | Configure Search Web Parts in SharePoint Server | Learn how to configure the following Web Parts that use search technology in a publishing environment:  
  Content Search Web Part  
  Refinement Panel Web Part  
  Taxonomy Refinement Panel Web Part  
  Recommended Items Web Part |
|  | Configure refiners and faceted navigation in SharePoint Server | Learn how to map a crawled property to a refinable managed property, enable a managed property as a refiner, and configure faceted navigation. |
|  | Configure result sources for web content management in SharePoint Server | Learn how to create and manage result sources for SharePoint Search service applications, and for SharePoint Server sites and site collections. |
|  | Create query rules for web content management in SharePoint Server | Learn how to improve search results by creating and managing query rules for SharePoint Search service applications, and for SharePoint Server sites and site collections. |
|  | Configure recommendations and usage event types in SharePoint Server | Learn how to create custom usage event types, how to add code to record usage events, and how to influence how recommendations are shown on a page. |
