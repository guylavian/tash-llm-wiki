# Test Lab Guide: Configure a highly available SharePoint Server 2013 Search topology

**APPLIES TO:** 2013 2016 2019 Subscription Edition SharePoint in Microsoft 365

This document is the Test Lab Guide version of the procedures that are described in Test Lab Guide: Configure a highly available SharePoint Server 2013 Search topology.

This document contains instructions for the following tasks:

Configure the three-tier farm test lab.

Install and configure new application servers named APP2, APP3, APP4, and APP5.

Install SharePoint Server 2016 on the new application servers.

Create and configure the Search service application.

Change the default search topology.

Create a Search Center site.

Test the search on the default Contoso team site on WFE1.
