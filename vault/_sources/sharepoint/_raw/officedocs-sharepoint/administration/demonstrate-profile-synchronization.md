# Test Lab Guide: Demonstrate profile synchronization for SharePoint Server 2013

**APPLIES TO:** 2013 2016 2019 Subscription Edition SharePoint in Microsoft 365

This document explains how to set up the SharePoint Server 2013 synchronization tool to synchronize profiles between SharePoint Server 2013 and a single Active Directory Domain Services (AD DS) domain controller.

This document contains instructions for the following:

Setting up the SharePoint Server 2013 three-tier farm test lab.

Creating a My Site web application and site collection and configuring settings.

Configuring the User Profile service application.

Creating a synchronization connection on APP1 to a directory service on DC1.

Demonstrating user profile synchronization.
