# Governance SharePoint Server

**APPLIES TO:** 2013 2016 2019 Subscription Edition SharePoint in Microsoft 365

Read these articles to learn about planning the different aspects of governance in SharePoint.

| **Content** | **Description** |
| --- | --- |
| What is governance in SharePoint? | Discover how establishing clear policies, roles, and responsibilities helps streamline deployment, secure your system, and maximize return on investment. |
| IT governance in SharePoint | Learn how to manage your SharePoint service. You can define clear offerings and SLAs, form a governing group, and implement policies to control unmanaged installations. |
| Application management and governance in SharePoint | Control and manage custom applications in your SharePoint environment: You can establish a customization policy, understand the SharePoint app model, manage branding guidelines, and implement application life-cycle processes. |
| Information management and governance in SharePoint | Plan an effective information architecture that organizes content, enhances searchability with metadata, and ensures your SharePoint solution meets business, security, and compliance requirements. |
| Plan for managed metadata in SharePoint Server | Plan your managed metadata strategy by creating term sets and taxonomies that help users consistently tag and find content across your SharePoint environment. |
| How to use the Managed Solutions Gallery | Deploy and manage code-based sandbox solutions centrally using the Managed Solutions Gallery, which allows you to control which solutions are available across your SharePoint Server environment. |
| eDiscovery and in-place holds in SharePoint Server | Discover, preserve, and export content across SharePoint Server and Exchange Server using the eDiscovery Center. The eDiscover Center lets you create cases, apply in-place holds, and manage legal discovery workflows. |
| Records management in SharePoint Server | Plan and implement a records management solution. It helps you classify, retain, and dispose of business records in SharePoint Server according to your organization's compliance and regulatory requirements. |
| Document management in SharePoint Server | Plan your document management solution by defining content types, implementing version control, configuring document libraries, and establishing policies that help your organization store, organize, and collaborate on documents effectively. |
| Workflow in SharePoint Server | Automate and streamline your business processes. You can design and deploy workflows in SharePoint Server that guide documents and tasks through predefined approval, review, and completion stages. |
