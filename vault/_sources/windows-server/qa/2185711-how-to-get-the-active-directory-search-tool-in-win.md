## Question

How can we get the Active Directory Search tool in Windows 10? I need to verify Windows accounts by searching AD, and don't find the AD search tool anymore. It used to appear as an icon of a small gold colored book. For my job, I have to
 be able to look up windows groups, and users. We just upgraded to Windows 10. Thanks, RickNPHX

## Answer (community) — community member

*upvotes: 29 · updated: 2018-06-22*

Hey Rick,

Hit Windows key + R and enter: optionalfeatures

Make sure "Active Directory Lightweight Directory Services" is enabled.

Are you able to use it now?
