## Question

Hello,  

We have an active directory domain on Windows server 2019.  Password policies are in place to enforce password changes with complexity.  

When a user who is being forced to change their password at logon tries to do so, they go through the process of changing the password and are not able to change the password or logon.  

The message "The users password must be changed before signing in"  this message keeps showing up no matter how many times the user goes through the process.  

This is happening for all users on all devices.  

If the user changes the password after being logged on by hitting ctrl+alt+del they are able to do so successfully.  

The server and the workstations are fully patched and up to date.
