## Question

I am trying to implement the Deny Read Access GPO on Removable Storage Access but it's denying the Write Access as well.

I would like my employees to be able to write data to a USB flash drive but I would like to prevent them reading from USB, the Deny Read Access GPO on Removable Storage Access is already implemented but it's denying the Write access as well, any guidance would be greatly appreciated.

A. Zamani

## Answer (community) — community member

*upvotes: 0 · updated: 2024-06-20*

For writing content to the USB drive, it's asking for administrator credentials.
