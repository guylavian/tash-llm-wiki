## Question

Hi All,

I have a Bigpond domain as my primary personal email. I have a requirement to use this on multiple devices. As I have found out on here the domain uses the IMAP and can only store calendar on the one device. The recommendation is to change to an Exchange or 365. I already do have a 365 account so I am wondering can I somehow have 365 adopt the Bigpond domain so I can retain the email address and subsequently use the calendar across multiple devices?

Thanks for using Microsoft products and posting in the Community.

I see that your email bigpond . com is a non-Microsoft domain mailbox and you want your bigpond . com's yo want the attribute to be exchange or Microsoft domain mailbox.

This is not possible, in the outlook program, you configure the bigpond .com mailbox to be an exchange or Microsoft domain mailbox. com mailbox for outlook program, because there is no cooperation, so it can't become exchange protocol, unless your mailbox domain service provider has cooperation with Microsoft, then it will become exchange protocol.

Actually your problem is how to synchronize the calendar, for IMAP protocol mailboxes, you can try calendar sharing or calendar backup import and export to load the current calendar to other devices. ps: the current calendar, once you modify the calendar, will not be synchronized.
