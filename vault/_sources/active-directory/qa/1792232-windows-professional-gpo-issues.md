## Question

GPO won't apply to Windows Professional  but works fine for Windows Business, the GPO applies the following Computer Configuration\Administrative Templates\Control Panel\Personalization\Force a specific default lock screen and logon image, the GPO previously worked then stopped working is a bug with the latest patches in Windows Pro that has broken this?

## Answer (community) — Q&A User [MicrosoftVendor]

Hi James Elliott,

If you suspect that the patch is causing the problem, you can try uninstalling the update to see if that fixes the problem. To do this, go to Settings > Update & Security > Windows Update > View update history > Uninstall updates. Find the update in question and click Uninstall. If the problem persists after uninstalling, please provide more details about the problem, such as relevant error screenshots.
