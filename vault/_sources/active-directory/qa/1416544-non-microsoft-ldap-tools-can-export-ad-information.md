## Question

Hello,

Recently my security team raise a concern to me. When a device is connect in my network, someone can easily export my Active Directory object information by run a third party LDAP tool. When he/she run the tool, he/she need to provide a credential which is any domain user's credential. So, now my concern is how to prevent this issue because it's a very critical vulnerability for me.

-  Users doesn't need to join the device in domain

-  Only domain user's credential can export everything

-  The LDAP tool collect the information through the network

How to prevent it? Thanks in advance.
