## Question

We are having a problem with activating users with Office 2016 for Mac via ADFS.

When the user enters their email address they are re-directed to our ADFS server to enter their password. That's fine.

When the user enters their password and press Sign In it starts loading and then re-directs straight back to the same login screen. No error is displayed or anything.

The real kicker: User is able to install OneDrive for Mac and sign-in with their email address and password via ADFS fine.So at the moment this only seems to be affecting Office 2016 for Mac as we are able to install and activate O365 for PC fine.  

Extra info:

-  This is happening with multiple users

-  Their user credentials are correct

-  No errors displayed in event logs on ADFS server

-  We are running ADFS 3.0

-  No infrastructure has been changed

-  Activating Office 365 for Mac has been working flawlessly up until now
