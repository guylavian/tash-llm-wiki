## Answer (community) — community member [MicrosoftVendor]

*upvotes: 0 · updated: 2024-07-09*

Hello,

Thank you for posting in Q&A forum.

You may reset your Azure VM Password using the Azure Portal. Follow these steps:

Sign in to the Azure portal.

Navigate to Virtual Machines.

Select the Windows VM for which you want to reset the password.

Under Support + Troubleshooting, click Reset Password.

Follow the wizard to update the credentials.

For more detailed information, please refer to: How to Reset a Azure VM Password? - GeeksforGeeks

I hope the information above is helpful.
