## Question

So we are about to be adding backup Domain Controllers at all my locations ( Should of been done awhile ago but now just getting to it ) the one thing I cannot figure out which is probably a simple thing is do I also need to buy user CAL License for the backup as well??    

Depending on the location we have between 50 and 100 licenses per main Domain Controller so will I also need another 50 to 100 just for the backup server as well?

## Answer (community) — Volunteer Moderator

*upvotes: 0 · updated: 2022-10-19*

Hi,    

No if the user count is same and you already have licenses no needs for additional licenses, If there are additional users accessing the DC and yes there will be requirement to purchase additional CALs please check here in detail - client-access-license
