## Question

Dear all,

Following GPO is in use for terminal servers:  

Hide these specified drives in My Computer  

Drive c is hidden.  

Unfortunately the setting does not work completely and users are still able to view drive c.  

For example if you use MS Word and save a document.   

If the user chooses "save as" and then "this pc", the full path is displayed in the address bar.  

With this full path the user can navigate through the complete folder structure and save documents in the most impossible places.

  

The GPO "restrict access to specified drives" prevents navigation, but access to folders like desktop and downloads is aggravated as well (but not impossible - this is a topic in itself).  

Is there a way to protect the c drive more efficiently?  

Thanks a lot  

With kind regards
