## Answer (community) — Microsoft Moderator [MicrosoftEmployee]

*upvotes: 0 · updated: 2022-01-11*

The way the AD FS component was installed does't really matter.     

If you want to check if it has all the correct claim rules, you can compare them with what would be generated by https://adfshelp.microsoft.com/AadTrustClaims/ClaimsGenerator.     

If you want to be able to manage the AD FS trust from the a remote machine using the MSOL PowerShell module, you can use the `Set-MSOLAdfsContext`.    

To help you in your switch from federation to PHS, make sure you have enable the password hash sync in the synchronization features (this will not change the way user authenticate, this just enables the sync of the hash - make you you do it in the syn features, not in the "Change user sing-in" section, this one changes how users authenticate). And use the stagged roll out described here: https://learn.microsoft.com/en-us/azure/active-directory/hybrid/how-to-connect-staged-rollout.
