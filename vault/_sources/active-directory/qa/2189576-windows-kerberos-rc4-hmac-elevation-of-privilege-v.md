## Question

Hi, 

Please help me to remediate this vulnerability.

Windows Kerberos RC4-HMAC Elevation of Privilege Vulnerability.

Windows Server 2019

Description

=========

Windows file `\Windows\System32\kerberos.dll` version `10.0.17763.2510` on a machine running `Windows Server 2019` is vulnerable to `CVE-2022-37966`, which exists in versions `&lt; 10.0.17763.3650`.  <br>  <br>The vulnerability was found in the Microsoft Security Response Center (MSRC) with vendor severity: `Critical`.  <br>  <br>The vulnerability can be remediated by installing `10.0.17763.3650`.
