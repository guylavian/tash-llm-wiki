## Question

Is it possible to enable sha2 support for kerberos?    

With groups policy under "Network security: Configure encryption types allowed for Kerberos"  we can only enable/disable:    

DES_CBC_CRC,DES_CBC_MD5,RC4_HMAC_MD5,AES128_HMAC_SHA1,AES256_HMAC_SHA1,Future encryption types.
