# ADFS AD and Claims Provider Trusts - Disabled User Still Able to Log in

## Question

My ADFS and AD domain are configured with some RP so users are able to authenticate using our local AD.    

We've decided to add a "Claims Provider Trusts" that is our company global so our users from our business inside of that local AD would be able to authenticate using the company global credential since it is more used and desktop integrated. everything is working fine, I had to implement the RP claims a little different so it gave me lot of work but working.    

The problem I have today is my local AD users that are account disabled are still able to authenticate. I guess this is because the token is getting generated by the company global CPT and not by the local AD anymore? And since the user is still active in the company global it is working? Yes, the user can move from our business unit to a different one inside of the same company so we disable the user from our local AD so they cannot access these resources anymore.    

The RPs are configured using our local ADFS - I cannot change them to the company global;    

Our local ADFS and company Global have this "federation/trust" between them and it is doing the magic to use that Claim Provider Trust.    

Any idea how I could make sure a disabled user in our local AD is not able to access our resources/RP anymore?    

Here is an example of the RP claim I had to create to make this "magic" happening:    

```
Rule1 = Get LOCAL_AD Username  
c:[Type == "http://schemas.xmlsoap.org/ws/2005/05/identity/claims/emailaddress"]  
 => add(store = "Active Directory", types = ("PRIOPS"), query = "mail={0};sAMAccountName;LOCAL_AD\adfs", param = c.Value);  
  
Rule2 = Send LOCAL_AD username as NameID  
c:[Type == "LOCAL_AD"]  
 => issue(Type = "http://schemas.xmlsoap.org/ws/2005/05/identity/claims/nameidentifier", Issuer = c.Issuer, OriginalIssuer = c.OriginalIssuer, Value = "LOCAL_AD\" + c.Value, ValueType = c.ValueType, Properties["http://schemas.xmlsoap.org/ws/2005/05/identity/claimproperties/format"] = "urn:oasis:names:tc:SAML:1.1:nameid-format:LOCAL_AD");  
  
Rule3 = Send Name as LOCAL_AD Username  
c:[Type == "LOCAL_AD"]  
 => issue(Type = "http://schemas.xmlsoap.org/ws/2005/05/identity/claims/name", Value = c.Value);
```

I'm not sure if I'm missing something or not, I really appreciate any advise!    

Thanks!
