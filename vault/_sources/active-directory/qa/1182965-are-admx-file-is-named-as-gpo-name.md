## Question

I want to know are ADMX file are named as GPO/Registry?

If yes then I coudnot find the [ActiveInstallService],[AddRemovePrograms]registry where does that located?

Does ADMX file contain all the registry Information?

## Answer (community) — community member

*upvotes: 0 · updated: 2023-02-23*

Hi. Thank you for your question and reaching out. I’d be more than happy to help you with your query No, ADMX files are not typically named after the GPO they are associated with. ADMX files are usually named after the product or application they are associated with. For example, the Google Chrome ADMX file is named "chrome.admx".
