## Question

I want to enable MFA for my existing on-prem active directory server.(server 2019)  

Need to prompt MFA when login users into their account from their PCs, Access RDS, File shares, using another apps..   

At least when login to the PC by using domain account.  

How can I achieve this with simple way and low cost.

## Answer (community) — community member

*upvotes: 0 · updated: 2021-09-02*

Hello,  

Thank you for your question.  

As far I know Microsoft has stopped for On-Prem MFA server.  

Online or Cloud MFA is available for Microsoft 365 and Azure application and services.  

However, you can look third party apps like DUO which support RDS Login and Local workstation Dual factor authentication.
