## Question

I need to upgrade my Active-Directory version but I need to upgrade my active directory. What are the newest Active-Directory versions I can have? And my client still must be Windows NT 4.0. What Active-Directory versions still support NT 4.0.

## Answer (community) — community member

*upvotes: 0 · updated: 2021-10-01*

Hello,  

Thank you for your question.  

As far I know Windows 2000 support Windows NT 4.0 But Microsoft has already stopped supported for that also,  

In your case it is highly recommended to Migrate your Windows NT 4.0 to Latest Windows AD 2019 or 2022.
