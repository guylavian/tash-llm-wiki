## Question

We have a small domain with one Windows 2012 Server domain controller. The server crashed with multiple drive failures about a month ago. The server was restored from backups but ever since this occurred we have been having intermittent network connectivity
 issues with a number of PC's. A few users had PC's with static IP addresses prior to the domain controller failure and they have not experienced any problems. However, all the DHCP clients are experiencing random network drops and are unable to access shared
 folders, lose network drive mappings, and get DNS errors trying to connect certain web sites. I even tried assigning static IP addresses to some of those PC's and they still randomly lose network connections. I've tried removing and re-adding the PC's to the
 domain. I've created a backup domain controller and tried running DNS on it and another member server. I've tried a number of other suggestions with no change. I can't tell if it's a DNS issue or a DHCP issue. Any help would be appreciated.
