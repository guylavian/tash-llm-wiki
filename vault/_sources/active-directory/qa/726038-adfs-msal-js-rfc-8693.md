# ADFS + MSAL.js + rfc-8693

> **Community Q&A (upstream).** Microsoft Q&A thread, not a Microsoft support statement.
> Accepted answers are frequently version-stale or wrong. Cite as

## Question

The first query is if they support integration with Single Page Applications and if they provide an official javascript library for this purpose. In the public documentation of ADFS there is a guide that indicates the use of ADAL.js, which is an archived library that is no longer maintained. In the README of ADAL.js it is indicated that the replacement is MSAL.js, which has open issues claiming support for ADFS.  

The second query is about what level of support ADFS has for the Token Exchange rfc-8693, which is used to implement on-behalf-of scenarios and resource consumption authorization on behalf of an interactive user when there is more than one microservices leap. For ADFS 2016 we found no support, but for ADFS 2019 we found no mention of it.
