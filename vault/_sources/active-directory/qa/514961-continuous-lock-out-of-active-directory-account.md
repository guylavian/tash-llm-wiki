## Question

We have active directory domain in our environment. It is configured in Windows Server 2019. And we have a account lockout policy for maximum 3 wrong password count and Screen lockout policy after 5 min of inactive uses. The problem we face is, some time some account continuously getting locked out in our client machine and the client machines are  running in windows 10. If the screen lock out after 5 min of inactivity or if user manually lock out the PC, and then when user tried to log on to his pc it shows "you reference account is currently locked out" even after the first attempt though password is correct. I tried with Clear Network Saved Credentials Using the Run Command using rundll32.exe keymgr.dll, KRShowKeyMgr but problem is not solved.
