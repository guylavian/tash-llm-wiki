## Question

i have a requirement that I should be able to search a user by his/her Employee Number, like if we put in sam account name or email address, we are able to search that user, the same way I want to search by employee number, in this environment its already there by employees id but I am not sure how it was done.

1.After my checking, in my test lab, I find you can click Advanced button below.

2.Click "Field"->User, you can only select many attributes, such as Employee ID (but there is no Employee Number).  

3.Starts with the Employee ID of the user. Then you will find the user.
