## Question

I have two Domain Controllers (DCs) in High Availability (HA) mode. They also serve as DNS servers, and their operating system is Windows Server 2019. They can ping each other and establish RDP connections internally. However, I cannot ping them from another server on the same network. I've disabled Windows Defender and cleared all Group Policy Objects (GPOs) on the DCs, leaving only the default ones. I've verified the RDP configuration, and it appears to be correct. However, I still need to reach them via RDP. How can I solve this problem?
