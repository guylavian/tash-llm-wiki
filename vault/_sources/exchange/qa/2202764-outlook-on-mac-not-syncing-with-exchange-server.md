# Outlook on Mac Not Syncing with Exchange Server

> **Community Q&A (upstream).** Microsoft Q&A thread, not a Microsoft support statement.
> Accepted answers are frequently version-stale or wrong. Cite as
> `web:https://learn.microsoft.com/en-us/answers/questions/2202764/outlook-on-mac-not-syncing-with-exchange-server (fetched 2026-07-25)` and verify against vendor documentation before relying on it.

## Question

Problem Description: We are using a Microsoft Exchange server that works correctly on Windows PCs. However, one user is experiencing an issue when trying to access their mailbox via Outlook on Mac.

After authentication, Outlook fails to sync data with the server. Additionally:

-  The user cannot send emails.

-  No error message is displayed, making troubleshooting difficult.

-  The issue is specific to the Mac environment, as email works fine on Windows.

Troubleshooting Steps Taken:

-  Verified account settings in Outlook (email address, server, connection method).

-  Tried signing in via Outlook Web App (OWA) → Works fine.

-  Restarted the application and the Mac → No change.

-  Checked network settings and firewall → No issues detected.

-  Removed and reconfigured the Outlook account → Issue persists.

Request for Assistance: We would like to know if a specific configuration is required for Outlook on Mac or if there is a solution to force synchronization with the Exchange server.
