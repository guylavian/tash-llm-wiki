## Question

Has there been any further update regarding the issue discussed here:

https://learn.microsoft.com/en-us/answers/questions/1290079/how-can-a-shared-exchange-mailbox-be-added-to-mail

We are having the same issue, and it renders us with people unable to work efficiently. Is there a solution that allows shared mailboxes to be added to and accessed by mac mail?

## Answer (community) — community member [MicrosoftVendor]

*upvotes: 0 · updated: 2023-09-18*

Hi @Jenny Ross  

I searched as much as I could and saw a lot of voices on this issue. The only workaround I found was setting an application password, but it is no longer useful as it is deprecated. So, I think there is currently no way to add a 2FA type shared mailbox to Mac Mail.

To be honest, I think this is an issue with Mac Mail not supporting 2FA authentication, so maybe you can try contacting Apple Support to see if there are other options.
