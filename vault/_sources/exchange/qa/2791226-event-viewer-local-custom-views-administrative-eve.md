## Question

I got this call today from an Unknown Caller/No Number stating they were from Microsoft Support informing me that my computer was displaying numerous errors on their report.   The Unknown Caller provided me with what I believed to be my License Number and
 instructed me on how to view these errors.  I wanted to first confirm that the License Number is correct.   I followed the instructions and did see up to 3,000+ errors listed.   I ended the call before doing anything else.  My question is how can I resolve
 these errors and clear this report.

This is a brand new computer, so how can it contain any errors already.  I am running Windows 10 Home.

Moved from: Windows / Windows 10 / Windows settings

## Answer (community) — community member

*upvotes: 2 · updated: 2018-01-29*

Hi Rochelle,

This technique is what most tech. support scams use to trick Windows users into thinking that their PC needs fixing. Technically, the Event Viewer allows you to monitor events in your system. This includes logs about programs, security, and other system
 events on your computer. If you see a logged error, it isn't always relevant unless you have observed or encountered an actual problem such as crashes or blue screen errors.
