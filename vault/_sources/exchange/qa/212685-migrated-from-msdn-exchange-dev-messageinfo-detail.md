Actually only Microsoft knows all meanings of these abbreviation in message tracking log, I'll share you some that I know:    

"UTH", "Under Threshold"    

"MTSSDSDM", "MTSSDSDM - MailboxTransportSubmission StoreDriverSubmission OnDemotedMessage"     

"MTSSDSDS", "MTSSDSDS - MailboxTransportSubmission StoreDriverSubmission Store Dispose Session"
