# Skype for business server 2015 with Exchange 2019

> **Community Q&A (upstream).** Microsoft Q&A thread, not a Microsoft support statement.
> Accepted answers are frequently version-stale or wrong. Cite as

## Question

I understand Exchange 2019 removes UM but will Skype for Business Server 2015 function at all with mailboxes located on Exchange 2019?

## Answer (community) — Q&A User [MicrosoftVendor]

*upvotes: 0 · updated: 2023-11-07*

The previous response is purely for Unified messaging support (voicemail).

Exchange server 2019 and Skype for business 2015 are supported for presence and chat. CU7 and upwards must be installed on the Skype for Business server.

https://learn.microsoft.com/en-us/exchange/plan-and-deploy/system-requirements?view=exchserver-2019#lyncskype-for-business-server-integration-with-exchange-2019
