# Exchange Online meeting room custom reply still sends even when invite is declined, any way to disable?

> **Community Q&A (upstream).** Microsoft Q&A thread, not a Microsoft support statement.
> Accepted answers are frequently version-stale or wrong. Cite as
> `web:https://learn.microsoft.com/en-us/answers/questions/1276762/exchange-online-meeting-room-custom-reply-still-se (fetched 2026-07-25)` and verify against vendor documentation before relying on it.

## Question

We currently have some rooms setup so that when a meeting invite is sent to the room and the automated assistant kicks in to accept/decline the meeting it will send a custom reply with details around meeting room best practices.

However, we noticed that even when the meeting is declined it will still add this custom reply to the response, which may get confusing for some user's that might glance over it thinking their meeting is good to go.

So far we have not found a way to get around this other then to disable the custom reply which is a good addition to the invite response overall.

Has anyone come across this? any suggestions?

## Answer (community) — Volunteer Moderator [Mvp]

*upvotes: 0 · updated: 2023-05-05*

It can't be disabled for just the declines because there is no difference in that respect from an acceptance email or a decline.
