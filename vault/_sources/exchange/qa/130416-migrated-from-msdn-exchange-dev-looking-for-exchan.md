## Answer (community) — Microsoft Moderator

*upvotes: 0 · updated: 2020-10-19*

Hi,    

Microsoft provides download files only for N-2 versions for an Exchange Server cumulative update (CU), where "N" is the latest CU. The latest version for Exchange 2016 is CU18, it's highly recommended to install the latest Microsoft Exchange Server update from the following Microsoft Learn article and keep your Exchange server up-to-date:    

Exchange Server build numbers and release dates
