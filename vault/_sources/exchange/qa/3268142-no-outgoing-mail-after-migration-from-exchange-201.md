## Question

Hello,

We recently migrated to Microsoft Office Exchange Server 2019 from 2013. Old users can receive but no longer send emails, but newly added users can
 send and receive. In OWA, messages get stuck in drafts. In EAC 2019, we see the warning 'Database is mandatory on UserMailbox', including for newly added users.  

We have tried to migrate the mailbox again as part of our troubleshooting. In Event Viewer we receive the warning, "The Microsoft Exchange Mailbox Replication service was unable to process jobs in a mailbox database.  

Database: Final Database  

Error: Couldn't find system mailbox 'bf5fd4e5-2027-418e-bb67-9d4bfe5804a0' in Active Directory."  

and the same warning for the mailbox '80e426f1-d795-4ff4-ba63-b0af4710cc8b'. We also receive Event Viewer errors, related to these mailboxes, stating 'Error accessing system mailbox: bf5fd4e5-2027-418e-bb67-9d4bfe5804a0|Microsoft.Exchange.Migration.MigrationMailboxNotFoundException|The
 migration mailbox for the organization is either missing or invalid.'  

We have tried PrepareAD and reestablished the system mailboxes, but this has not helped.

Exchange 2019 is running on Windows Server 2019 as a Hyper-V VM.   

Please advise. Your rapid assistance would be much appreciated.  

Thank you,  

Stuart
