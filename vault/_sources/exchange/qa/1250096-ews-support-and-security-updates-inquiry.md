## Question

Dear Microsoft Support Team,

I am reaching out to inquire about the current status and future plans for the support of Exchange Web Services (EWS). In a communication from Microsoft in 2018, it was mentioned that EWS would no longer receive feature updates, but security updates and support for production deployments would continue.

Considering that migrating our existing solutions to the Microsoft Graph API would require significant time and effort, we are keen to understand Microsoft's stance on EWS support and security updates. Specifically, we would like to know:

-  Will Microsoft continue to provide security updates for EWS?

-  Is there a planned timeline for discontinuing support for EWS, and if so, when will that occur?

Understanding Microsoft's commitment to EWS will help us make informed decisions on our existing solutions and potential migration plans. 

I appreciate your assistance in addressing these concerns and look forward to your prompt response.
