# Outlook for Mac is not connecting to Exchange 2019

> **Community Q&A (upstream).** Microsoft Q&A thread, not a Microsoft support statement.
> Accepted answers are frequently version-stale or wrong. Cite as
> `web:https://learn.microsoft.com/en-us/answers/questions/1179040/outlook-for-mac-is-not-connecting-to-exchange-2019 (fetched 2026-07-25)` and verify against vendor documentation before relying on it.

## Question

We have an Exchange 2019 server configured with a DAG, and we are encountering an issue where our Mac users are unable to connect to the Exchange servers using Outlook. The problem affects all Mac users, and the root cause is unknown.

## Answer (community) — Q&A User

*upvotes: 0 · updated: 2023-02-16*

Configure the Exchange server to support Compatible mode by using the instructions from KB article 980436.

For more detail - https://support.microsoft.com/en-us/topic/outlook-for-mac-clients-cannot-connect-to-exchange-server-bb7690e0-975a-7d95-a29b-b8bf5e787cb3
