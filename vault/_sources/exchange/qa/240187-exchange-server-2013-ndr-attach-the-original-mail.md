## Answer (community) — community member

*upvotes: 0 · updated: 2021-01-22*

Do you mean attaching the origin message to the NDR message?  As I know, it can't be realized. As NDR is generated by the Exchange system, what you can customize has been listed here: https://learn.microsoft.com/en-us/exchange/mail-flow/non-delivery-reports-and-bounce-messages/ndr-procedures?view=exchserver-2019    

The origin message can be found in the sender's "Sent Items", why you want that in NDR?    

You can search for some third-party tools or Outlook add-ins that can make this, but we would not garentee their safety.
