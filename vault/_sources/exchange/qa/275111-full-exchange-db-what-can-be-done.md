## Answer (community) — Volunteer Moderator [Mvp]

*upvotes: 1 · updated: 2021-02-16*

-  Do a full Exchange aware full backup to clear the transaction logs.     

-  Increase the available space on that drive    

-  Move all the mailboxes to another database    

-  Enable circular logging if none of the above is possible: https://learn.microsoft.com/en-us/exchange/configure-circular-logging-for-a-mailbox-database-exchange-2013-help
