## Question

Hi All,  

Just to check whether is it possible to update my exchange server cu from 12 to 19. The .Net version is already 4.8

## Answer (community) — Q&A User

*upvotes: 0 · updated: 2021-03-11*

Hi @soapy   ,    

Yes, its possible to upgrade from Exchange 2016 CU12 to CU19.  Since  you already installed .NET 4.8, please plan to update the Exchange CU19 immediately by installing other pre-requisites as .NET 4.8 is not supported with CU 12.    

     

Upgrade steps:
