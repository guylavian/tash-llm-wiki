## Question

Since the change of MSN.com to its new format, I have been unable to post comments or reply to comments on MSN.com news stories where others are able to comment.  I have tried posting with my facebook account sign-in; and I have tried posting using my MSN
 account sign-in.  Neither seems to work.  If I make a comment or reply to a comment and then post it, the comment will appear on the screen as if it is posted on the forum.  And, even if I leave the site and return to it later, the comment that I made seems
 to appear.  HOWEVER, if I access the same MSN.com news item using a different browser (e.g., Google Chrome), my comment does not appear.  So, it really is not posted.  Normally I use Internet Explorer as my browser.  However, I have tried posting comments
 using IE, Chrome, Firefox, and the MSN (the butterfly) browser -- none of these work for me.

Adding to my confusion, I tried posting a comment to an MSN.com news article using my grandson's computer.  There I used Google Chrome and signed in with a G-mail address and password.  When I went back to my own computer to check whether I could see that
 posted comment, I could see it when I use IE as the browser; but I could not see it when I use Chrome or Firefox as the browser -- so, I really do not know whether it is posted or not.

Does any one have any insights as to what is going on here and suggestions on how to get so that I can post on MSN.com news items with some reliability?

I do realize that this question has been asked before and I reviewed many of the responses -- but nothing seemed to be applicable.

FYI.  I am using a Dell Latitude E5530, with Windows 7 Professional, Service Pack 1.
