## Question

Existing environment is Exchange Hybrid 2013 co-existing with O365. Possible to add-on Exchange 2016 as hybrid server under free license? Before remove exchange 2013 from the configuration?  

Source Link: https://social.msdn.microsoft.com/Forums/office/en-US/b35047cf-f4a4-4aa9-b425-65bc6912eee9/exchange-hybrid-coexisting-with-o365?forum=exchangesvrdevelopment

## Answer (community) — community member

*upvotes: 0 · updated: 2020-12-16*

You could use an unlicensed Exchange 2016 as hybrid server temporary.   

Considering security and compliance requirements, if you need to use Exchange 2016 for a long time, it is recommended that you purchase a license.
