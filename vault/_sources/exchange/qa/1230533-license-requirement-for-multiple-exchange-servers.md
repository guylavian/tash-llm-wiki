## Question

Hi,
We want to install two exchange mail servers each on different host. How many server licenses do we need to purchase? Do we need to purchase total two licenses or only one is enough? Please guide.
Thanks

## Answer (community) — Volunteer Moderator [Mvp]

*upvotes: 0 · updated: 2023-04-14*

You will need two licenses, one for each installation.
It can be the same license key if you are licensed correctly so you will need to talk to your license reseller.
