## Answer (community) — community member

*upvotes: 1 · updated: 2020-11-25*

Hi ,    

The Exchange 2019 server licensed as a trial edition only could used 180 days. If you want to keep using the server beyond 180 days, you'll need to enter a product key or the Exchange admin center (EAC) will start to show reminders that you need to enter a product key to license the server.    

For more information you could refer to: Enter your Exchange Server product key
