## Question

Just wanted to know if SingleItemRecoveryEnabled flag is set to true when a mailbox is migrated from Exchange Online to Exchange On-premise.

During our analysis in Hybrid, we could see that when a mailbox is migrated back from Exchange Online to Exchange On-premise, SingleItemRecoveryEnabled flag is set to true. Is this expected? Since the mailbox is now in On-premise, shouldn't it be disabled?
