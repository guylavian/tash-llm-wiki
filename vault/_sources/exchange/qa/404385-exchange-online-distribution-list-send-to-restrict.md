## Question

Dear All,  

I have created a distribution list and using the delivery management settings I have set the list to only allow messages from inside my organisation and restricted it further to only accept messages from another distribution list.  This achieved my goal that external senders cannot send to this list and only the internal senders who I designated could send to it.    

My problem is I have found that membership of the restricted list prevents external senders sending to the individual mailboxes which are included in it.  My expectation was that the use of the list by external senders would be prohibited, but individual members could still receive messages directly.  

Is this behaviour working as intended?  

Thank you,  

Mr Fox
