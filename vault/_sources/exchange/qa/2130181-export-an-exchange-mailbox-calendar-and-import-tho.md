## Question

Would like to eliminate Exchange mailbox calendars and convert to 365 Group for ease of collaboration with Teams.  Need to transfer all calendar events/entries to the new 365 Group Calendar.  Need to do this with multiple Exchange mailboxes that are used only for the calendar function.

Issue: 

You need to export your Exchange mailbox calendar and import those events into your 365 group/team calendar.

Solution: 

In the Exchange Admin Center, select the mailbox you want to export and select Export. After importing, you need to switch to the list view twice for the shared calendar to appear in the list view. Then, select all events and drag the events into the Group calendar of which I am also an owner.
