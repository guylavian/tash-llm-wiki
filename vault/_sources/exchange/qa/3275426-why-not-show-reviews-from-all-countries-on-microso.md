# Why not show reviews from all countries on Microsoft Store?

> **Community Q&A (upstream).** Microsoft Q&A thread, not a Microsoft support statement.
> Accepted answers are frequently version-stale or wrong. Cite as
> `web:https://learn.microsoft.com/en-us/answers/questions/3275426/why-not-show-reviews-from-all-countries-on-microso (fetched 2026-07-25)` and verify against vendor documentation before relying on it.

## Question

I'm an independent developer of an application on Microsoft Store, currently struggling to increase my user base. In this situation, it's very frustrating to see that several existing users have given my application top reviews, all written in English, but
 these reviews are only shown in their home countries, because that's how the review system works: People browsing for apps can only see reviews posted in their own countries. As a result, many potential customers who find my application's page on Microsoft
 Store will see zero reviews, most probably leading to fewer installs than if they could see those great reviews.

When I search the internet about this problem, I find many posts on the same topic: Both application users and application developers want the reviews to be shown globally. The users want to be informed about what they're installing, and developers like
 me want the reviews to reach out. In the cases where Microsoft's agents have responded to such posts, they have recommended users to switch region, so they can see other reviews. That's not helpful.

What can be the reason for this design choice? It would reduce my frustration if at least I could find a rational explanation. As far as I can see, even Microsoft must be losing money on this, since people generally will buy less software on their Store.

And more importantly, where can I direct my feedback, so that the relevant developers, designers and managers at Microsoft can reconsider this design and maybe change it in a future update?
