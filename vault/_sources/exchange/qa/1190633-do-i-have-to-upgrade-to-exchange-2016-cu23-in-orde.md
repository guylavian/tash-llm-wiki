## Question

```
Hello Community,

I have Exchange 2016 with CU22 patched with the latest SU from Nov 2022, Details are below:

| Exchange Server 2016 CU22 Nov22SU | November 8, 2022 | 15.1.2375.37 | 15.01.2375.037 |

However, now I can see on Exchange build and releases page that Security updates we released for CU23 after Nov22SU.

| Header 1 | Header 2 | Header 1 | Header 2 |
| -------- | -------- | -------- | -------- |
| Exchange Server 2016 CU23 Mar23SU   | March 14, 2023   | 15.1.2507.23   | 15.01.2507.023   |
| Exchange Server 2016 CU23 Feb23SU   | February 14, 2023   | 15.1.2507.21   | 15.01.2507.021   |
| Exchange Server 2016 CU23 Jan23SU   | January 10, 2023   | 15.1.2507.17   | 15.01.2507.017   |

Does this mean that security updates will no longer be released for CU22, and we have to upgrade to CU23 in order to get the latest Security updates?

Or does this mean that the security updates released fro CU23 like the below ones are not relevant to CU22?

Many thanks in advance.
```
