## Question

I tried adding the Office 365 Exchange Online API in the application's API permissions, but couldn't find the API in the APIs used by my organization. Do I need to purchase a subscription for any service?

## Answer (community) — Volunteer Moderator [Mvp]

*upvotes: 1 · updated: 2024-12-24*

Try searching for it via the GUID, 00000002-0000-0ff1-ce00-000000000000.

If there are still no matches returned, you would need a subscription that includes any Exchange Online plan. If you don't have such, sign up for an O365/M365 trial, for example this one: https://go.microsoft.com/fwlink/?linkid=2244732&clcid=0x409&culture=en-us&country=us
