## Question

I wanted my Window 10 File Explorer to display .pdf file previews like my Windows 7 so I started researching and came up with several different solutions, none of which worked for me.

Prime among the solutions was Option 1:

-  Open file explorer

-  Click view on the top of the file explorer.

-  Select preview pane option and see if it helps.

And Option 2:

-  Open the reader,

-  Go to Edit

-  Then Preferences

-  Go to General Tab

-  And check "enable PDF thumbnail previews"

Even after using Option 2, it still didn’t work but then after going to Help > Repair Installation in Acrobat Reader DC it works just fine.
