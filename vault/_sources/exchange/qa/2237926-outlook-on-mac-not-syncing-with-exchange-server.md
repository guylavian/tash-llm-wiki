For some of the reasons behind this issue, some of them are described below:

-  Offline Mode: When using Outlook for Mac in offline mode, it does not synchronize with Exchange and hence causes synchronization issues.

-  Connection failures: Network or server related issues (such as slow or unstable connections, outdated passwords, or outdated macOS) may make the initial connection to the Exchange Server difficult.

-  Cache issues: A corrupted Outlook cache may prevent Mac mail from synchronizing with Exchange issues, so follow some experts' advice to delete or recreate the cache.

-  Incorrect settings: Misconfigured settings such as date and time, server address, etc. can cause such synchronization problems. Check the settings and make necessary adjustments to fix the problem.
