Is there a way to setup a user to access an exchange online shared folder through the web interface?  I have a user without Outlook desktop that I want to allow access to a shared folder?  They only need read access.  The user is licensed with exchange online plan 1.

*upvotes: 1 · updated: 2020-10-21*

Yes, you should be able to do that just fine from the webmail/OWA. Right-click on the "Folders" section in the top left corner, select "Add shared folder", then enter the name/address of the mailbox from which you want to open it. Alternatively, click your profile picture in the top-right corner, select Open another mailbox.
