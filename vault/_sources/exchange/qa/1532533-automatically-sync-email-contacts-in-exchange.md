## Question

We are looking to automatically sync contacts for outlook desktop and mobile through the Microsoft Exchange admin center. What settings or policies could I change or enable to allow the contacts tot sync across devices?

## Answer (community) — Microsoft Moderator

*upvotes: 0 · updated: 2024-02-15*

Hi @c.willard  

We are looking to automatically sync contacts for outlook desktop and mobile through the Microsoft Exchange admin center.

If the contacts are created as mail contacts in Exchange Admin Center, the users will be able to see these contacts in address book in Outlook.

To me there is no need to manually sync these contacts.

In Outlook for mobile you should also be able to see the contacts in Contacts.

If you are not seeing newly created contacts, please wait some time for the Global Address Book to be updated.
