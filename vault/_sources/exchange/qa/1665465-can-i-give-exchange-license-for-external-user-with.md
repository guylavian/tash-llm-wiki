## Question

Hi All,

I have an account with a Microsoft 365 E5 Developer license. I can invite a few external members into my organization, and I can assign licenses to them. They can use Microsoft 365 software like MS Teams and SharePoint normally. However, they cannot log into Outlook (Exchange) even though I checked and saw that Microsoft 365 E5 Developer includes Exchange Online Plan 2. I don't know if this is due to some setting or if there are other conditions missing to be able to use email. Can anyone help me with this issue?

## Answer (community) — Q&A User [MicrosoftVendor]

*upvotes: 0 · updated: 2024-05-13*

Hi，

Thanks for posting your question in the Microsoft Q&A forum.

Based on your description, I conducted related experiments to invite external people in the Microsoft Entra Center.

After assigning the M365 license, I don't see that external mailbox in Exchange Online.

I tried to log in using my external email account and password, but an error occurred.

So it is not possible to log in to Outlook by assigning a license to external users.
