is it a default behavior ?    

-No, according to my personal experience, all should have. But it's Exchange forum here, you want troubleshooting AAD Connect, it's suggested to start a new thread with azure-ad-connect tag:https://learn.microsoft.com/en-us/answers/topics/azure-ad-connect.html    

You can try adding X500 address manually, this script might help:    

```
Import-Csv .\importsip.csv | foreach {Set-Mailbox -Identity $_.alias -EmailAddresses @{add=$_.x500}}
```
