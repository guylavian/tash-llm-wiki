## Question

I was reviewing Microsoft's documentation on Exchange Server Cumulative Updates and found conflicting information, so I just want to clarify what the release schedule is.

One Microsoft article from Apr 20, 2022 says "Historically, we have released quarterly CUs [but] [t]oday, we are announcing changes to our update delivery model for Exchange Server. We are moving to a release cadence of two CUs per year – releasing in H1 and H2 of each calendar year, with general target release dates of March and September.": https://techcommunity.microsoft.com/t5/exchange-team-blog/released-2022-h1-cumulative-updates-for-exchange-server/ba-p/3285026#:~:text=Today%2C%20we%20are%20announcing%20changes,dates%20of%20March%20and%20September.

However, this other Microsoft article from Feb 21, 2023 says "Exchange follows a quarterly delivery model to release Cumulative Updates": https://learn.microsoft.com/en-us/exchange/new-features/updates?view=exchserver-2019

So did Microsoft revert the schedule back to quarterly, or was the newer documentation simply not updated?
