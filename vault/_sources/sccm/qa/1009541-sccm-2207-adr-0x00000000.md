Thank you for posting in Microsoft Q&A forum.    

The error 0X00000000 means success like the error description said. It means the Software Update Group created by ADR deployed to client successfully.    

But if the updates in the Software Update Group is not required for the clients, or clients can not do the scan successfully, clients will not get the updates.    

You may click "Show Members" of your Software Update Group created by ADR, and check the statistics to see is there any clients show "Required" or "Not Required" for the updates?
