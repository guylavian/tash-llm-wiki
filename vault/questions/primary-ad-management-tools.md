# What are the primary Active Directory management tools?

**The four primary tools for managing AD DS are ADAC (dsac.exe), the ActiveDirectory PowerShell module, GPMC (gpmc.msc), and ADUC (dsa.msc).**

## Answer

### 1. Active Directory Administrative Center (ADAC / dsac.exe)
The primary graphical tool for AD DS management, introduced in Windows Server 2008 R2. Built atop the ActiveDirectory PowerShell module — every GUI action translates to cmdlets visible in its **PowerShell History Viewer**. Key capabilities: browse/manage users/groups/computers/OUs, enable the Recycle Bin, manage Fine-Grained Password Policies, cross-forest management, and RODC staging. Requires ADWS (TCP 9389) on at least one DC.

### 2. ActiveDirectory PowerShell Module
Over 100 cmdlets (part of RSAT) covering every AD DS operation: `Get-ADUser`, `New-ADUser`, `Get-ADGroup`, `Enable-ADOptionalFeature`, `Restore-ADObject`, `Install-ADDSDomainController`, etc. The scripting foundation that ADAC itself uses.

### 3. Group Policy Management Console (GPMC / gpmc.msc)
The authoritative tool for [[group-policy]] administration: forest/domain/site/OU tree, GPO linking, permissions, Resultant Set of Policy modeling, and GP Results reports.

### 4. Active Directory Users and Computers (ADUC / dsa.msc)
The legacy MMC snap-in (Windows 2000) for core user/group/computer/OU operations and the Delegation of Control Wizard. For advanced tasks (Recycle Bin, FGPPs, scripting) ADAC is preferred.

All four ship with **RSAT (Remote Server Administration Tools)** and are installed on domain controllers by default.
