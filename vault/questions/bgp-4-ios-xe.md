# What is BGP-4 and how does it work on IOS XE?

**BGP-4 (Border Gateway Protocol version 4) is the interdomain path-vector routing protocol. It exchanges loop-free reachability between autonomous systems (ASes) over TCP port 179, carrying the ordered AS_Path with every route.**

## Path-vector operation

Each route carries the ordered **AS_Path** — the list of AS numbers the route has traversed. A router rejects any update whose AS_Path already contains its own AS (loop prevention). BGP installs **one best path** per prefix by default, and a device runs one BGP process / one AS but many address families.

A critical IOS XE rule: a BGP **next hop must be reachable** (usually via the IGP) for a route to be usable. Routes whose next hop is unreachable are not installed in the routing table.

## AS numbers

- **2-byte ASNs**: 1–65535
- **4-byte ASNs**: 65536–4294967295
- **Two notations**: **asplain** (default, e.g. 234567) and **asdot** (`bgp asnotation dot`, e.g. 1.169031)
- Under asdot, a 4-byte regex must escape the literal dot (`1\.14`) and switching notation requires `clear ip bgp *`
- Private 2-byte range: 64512–65534; Cisco does **not** strip private ASNs unless configured with `neighbor remove-private-as`

## Next hop & peering

- **eBGP** sets the next hop to the advertising peer's interface IP; peers are expected to be directly connected
- **iBGP** keeps the eBGP next hop unchanged — it must be reachable or rewritten with `next-hop-self` (for non-reflected routes)
- `neighbor ebgp-multihop` + `update-source loopbackN` relaxes the directly-connected requirement for stable loopback peering; add `disable-connected-check` for single-hop loopback eBGP

## Best-path selection

Driven by **[[bgp-path-attributes]]**: AS_Path (shorter preferred), Local_Pref (highest preferred, iBGP only), MED (lower preferred, compared only within same neighbor AS by default — unless `bgp always-compare-med`), Origin (IGP > EGP > Incomplete). Cisco treats a **missing MED as 0 (most preferred)** — configure `bgp bestpath med missing-as-worst` to invert this.

## Scaling

- **[[bgp-route-reflector]]** avoids a full iBGP mesh by reflecting iBGP-learned routes; loop avoidance uses Originator-ID and Cluster-list; only `set ip next-hop` is honored in outbound route-maps on reflected routes
- **Route dampening** suppresses flapping routes: each flap adds penalty 1000; suppress at 2000, reuse at 750, 15-min half-life. A single flap never suppresses — at least 2 flaps within a half-life are needed

## IOS XE configuration basics

```
router bgp 65000
  bgp router-id 10.0.0.1
  neighbor 10.0.0.2 remote-as 65001
  neighbor 10.0.0.2 ebgp-multihop 2
  neighbor 10.0.0.2 update-source loopback0
  !
  address-family ipv4 unicast
    neighbor 10.0.0.2 activate
    network 192.168.1.0 mask 255.255.255.0
  exit-address-family
```
