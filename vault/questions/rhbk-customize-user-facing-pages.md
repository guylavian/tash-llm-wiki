# Customizing the look of RHBK user-facing pages

RHBK has **two theming tracks** depending on which pages you want to customize:

## Classic Freemarker themes (Login, Email, Welcome)

These use Apache Freemarker templates, CSS, images, and message bundles under `themes/<name>/<type>/`.

**Theme types** — Login, Account, Admin, Email, Welcome. All except Welcome are set per-realm via **Realm Settings → Themes** in the Admin Console. The Welcome theme is server-wide (`--spi-theme-welcome-theme=custom-theme`) (rhbk-26-2-themes.md:22-43).

**Creating a theme:**
1. Create `themes/mytheme/login/theme.properties` with `parent=keycloak` (or `base`).
2. Override templates by copying `.ftl` files from the bundled JAR (`keycloak-themes-<VERSION>.jar`) into your theme directory.
3. Add CSS under `resources/css/`, reference via `styles=css/styles.css` in `theme.properties`.
4. Override text via `<type>/messages/messages_en.properties`.
5. Add custom IdP icons via `kcLogoIdP-<alias>` in `theme.properties` (rhbk-26-2-themes.md:48-265).

**Theme properties** include `parent`, `import`, `common`, `styles`, `locales`. Properties support `${system.property}` and `${env.ENV_VAR}` substitution with optional defaults (rhbk-26-2-themes.md:99-126).

**Disable caching during development:**
```
kc.sh start --spi-theme-static-max-age=-1 --spi-theme-cache-themes=false --spi-theme-cache-templates=false
```
Re-enable in production. Purge cache manually by deleting `data/tmp/kc-gzip-cache` (rhbk-26-2-themes.md:61-98).

**Deploy** by copying to `themes/` directory or packaging as a JAR with `META-INF/keycloak-themes.json` into `providers/` (rhbk-26-2-themes.md:290-315).

## React-based themes (Admin Console, Account Console)

The Admin and Account consoles are built on React. Customize them using npm packages:
- `@keycloak/keycloak-admin-ui` — Admin Console base theme
- `@keycloak/keycloak-account-ui` — Account Console base theme

Install with `pnpm install @keycloak/keycloak-account-ui`, add `<KeycloakProvider>` with server/realm/client config, and use the exported React components (rhbk-26-2-theme-react.md:19-54). Translations use `i18next` with `i18next-fetch-backend` (rhbk-26-2-theme-react.md:41-52).

## Theme SPIs (programmatic customization)

- **Theme Selector SPI** — programmatically choose which theme per request (e.g. mobile vs desktop). Implement `ThemeSelectorProviderFactory` + `ThemeSelectorProvider`, deploy as a JAR in `providers/`, run `kc.sh build` (rhbk-26-6-providers.md:22-81).
- **Theme Resource SPI** — control how templates/resources are loaded, especially for shipping extra templates with a custom provider. JAR with templates under `theme-resources/templates` (rhbk-26-2-theme-react.md:61-69).
- **Locale Selector SPI** — override locale resolution by extending `DefaultLocaleSelectorProvider` (rhbk-26-2-theme-react.md:70-88).

## Migration from RH-SSO 7.x

The old AngularJS Admin Console (`keycloak` theme) and old Account Console have **no migration path** to the React-based consoles (`keycloak.v2`). You must rebuild custom console themes from scratch using the React packages. Login/email Freemarker themes carry over with template re-checks against the new bundled templates (rhbk-26-2-migrating-themes.md:18-21, 22-30).
