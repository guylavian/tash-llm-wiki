# What is policy-based routing and when is it used?

**Policy-based routing (PBR)** is a process where a router applies a route map to packets arriving on an interface *before* performing the destination-based routing table lookup, forwarding matched traffic according to the map's `set` clauses rather than the FIB's longest-prefix match (`cisco-pi-policy-based-routing-default-next-hop-routes.md:43-48`).

## When it's used

PBR is used when you need to route packets based on criteria other than destination IP, such as:
- **Source-sensitive routing** — forward traffic from certain source subnets via a specific next-hop or WAN link
- **Protocol-sensitive routing** — route HTTP traffic one way, VoIP another (`cisco-pi-policy-based-routing-default-next-hop-routes.md:46-48`)
- **Equal access / traffic engineering** — interactive vs batch traffic over different links
- **Dedicated links** — steer traffic onto a specific circuit based on match criteria
- **SGT-based PBR** — forward by Cisco TrustSec Security Group Tag instead of IP/ACL (`_sources/cisco-ios-xe/protocol-independent-routing.md:34`)

## How it works

Apply `ip policy route-map <tag>` on an interface (transit traffic) or `ip local policy route-map <tag>` (router-originated traffic). The route map matches packets via `match ip address` (ACL/prefix) or `match length`, then acts via `set ip next-hop`, `set interface`, or `set ip precedence` (`entities/policy-based-routing.md:28`).

## Critical caveats

- **Enabling `ip policy route-map` disables fast switching** for all packets on that interface (`cisco-pi-policy-based-routing-default-next-hop-routes.md:62-63`)
- **Local PBR + TCP:** router-sourced TCP fails unless the device has a RIB/FIB entry for the remote host; UDP/ICMP still follow the policy (`_sources/cisco-ios-xe/protocol-independent-routing.md:27`)
- **`set ip next-hop verify-availability`** prevents ARP-loop blackholes by checking the next-hop is a CDP neighbor before policy-routing — requires CDP, a directly-connected Cisco next hop, and doesn't work with distributed CEF (`entities/policy-based-routing.md:33`, `_sources/cisco-ios-xe/protocol-independent-routing.md:28`)
