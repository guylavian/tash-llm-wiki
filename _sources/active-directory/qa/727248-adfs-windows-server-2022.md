Hello, there is detailed documentation of adfs 2022. The one I find is only up to 2019. Thank you.

## Answer (community) — Microsoft Moderator [MicrosoftEmployee]

*upvotes: 2 · updated: 2022-02-14*

There is no documentation as the AD FS version in Windows Server 2022 is essentially the same version as in Windows Server 2019. AFAIK there aren't any new features.  

The only few cases that I dealt with in AD FS on Windows Server 2022 were related to TLS 1.3 support. And that's an OS thing, not an AD FS/WAP thing.
