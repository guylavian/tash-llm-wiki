## Question

Exchange 2016, server 2016  

My backup software is on the fritz and I want to check if exchange detects it successfully ran.  

Where are the audit logs stored that merge with the database when it detects the database has been backed up?  

I am seeing a folder in c:\program files\install path\database with a folder with a mailbox database name I do not recognize.  Inside it are recent txt documents since the last backup was attempted to run.  I have renamed the original database and moved it to a new partition when the server was created but don't remember the original database name.  

In the ECP, I have moved the 4 transport log files that it allowed me to move to another partition than the C: and database partitions under Server.  I do not see the audit files I am looking for in those folders.

Hi @Susan Dodds   ,  

According to my research and check. I didn’t see any audit log in database files and transport log files.  

In order to better solve this issue, I want to confirm with you the following points:  

-  What do you mean by "Exchange database audit log?  

-  Is it generated by your backup tool?  

-  What is the backup tool you are using?

About the original database name.  

1.According to my test. I changed the database name in EAC, but dataset name not be changed in C:\install path\database. Could you see it?  

  

2.How long have you changed? The admin audit log will retention 90 days by default. If you changed during this period, you could run the following command to see the changes made to the database name.

```
Search-AdminAuditLog -StartDate <> -EndDate <> -Cmdlets Set-Mailboxdatabase -Parameters Name
```
