## Answer (community) — Microsoft Moderator

*upvotes: 0 · updated: 2020-12-11*

Hi,    

To my knowledge, the message recall feature is based on the client side (Outlook).    

The Exchange server isn't able to perform a message recall by itself.    

So it is not possible to do that.
