## Answer (community) — community member

Hi,

Do you mean to configure mail flow for different users in the same Exchange organization? In fact, there is no need to configure mail flow in this case.

Configuring mail flow is to route mail from internal or external senders to the Internet. For details on how to configure mail flow for Exchange Server2013, you can refer to this article: Configure mail flow and client access.
