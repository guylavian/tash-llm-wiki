## Question

Apologies if this is a simple question. 

We are a small business. 5-6 people on basic/premium 365 office business  package.

Currently using Code2 to manage project email (legacy issue)

We have around 300-400 project each year

Each year the total email folder size is around 10-15Gb (slowly getting bigger each year, but only a little) 

We want to move across to having everything on Microsoft/exchange rather than code2.

I think we have a public folder limit of 50GB(?) for our license?

I think this limit is for each public folder(?) not the total for all public folders

So if I set up a public folder for each years project (2023, 2024, 2025,…) then we are likely to be well within the 50Gb limit. 

I just wanted to check that the 50Gb limit was for each public folder, rather than the combined total for all public mailbox. If its for the combined then we are likely to exceed the 50Gb limit. 

Many thanks for any help - Owen

Hi, @Owen B

Thank you for posting your question in the Microsoft Q&A forum.

According to your description, you want to know if the 50Gb limit applies to each public folder. Yes, the 50GB limit applies to each public folder, not to all public mailboxes combined.

Refer to: https://learn.microsoft.com/en-us/exchange/collaboration/public-folders/public-folders?view=exchserver-2019#public-folder-quotas
