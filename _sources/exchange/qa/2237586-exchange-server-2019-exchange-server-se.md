## Question

Dzień dobry

Proszę o udzielenie odpowiedzi na poniższe pytania:

-  Proszę o potwierdzenie że produkt MS Exchange Server 2019 cu15 zostanie zakończone wsparcie w październiku 2025 ?

-  Czy po wskazanej powyżej dacie będzie możliwość zakupienia MS Exchange Server 2019 z oficjalnego sklepu Microsoft lub przez Partnerów ?

-  Czy planowana wersja produktu MS Exchange Server SE będzie dostępna w wersji On-Premises ?

-  Czy przewidywana jest wersja licencjonowania wieczystego dotycząca MS Exchange Server SE ?

-  Proszę o rozwinięcie terminu "Licencji Hybrydowej" która ma się pojawić MS Exchange Server SE ?

## Answer (community) — Q&A User

*upvotes: 0 · updated: 2025-03-24*

Hi @Maciej Kacperski  ,

Oto odpowiedzi na Twoje pytania:

-  Tak, planowane zakończenie wsparcia dla Exchange Server 2019 (w tym CU15) jest w 14 październiku 2025. 

-  Po zakończeniu wsparcia trudno będzie kupić Exchange Server 2019 bezpośrednio od Microsoftu, ale partnerzy mogą jeszcze sprzedawać pozostałe licencje. 

-  Tak, Exchange Server SE będzie dostępny jako wersja On-Premises. To oznacza, że będzie można zainstalować go na własnych serwerach, tak jak wcześniejsze wersje.

-  Tak, Microsoft planuje udostępnić wieczyste licencje dla Exchange Server SE, co oznacza, że kupując tę licencję, będziesz mieć prawo do korzystania z oprogramowania bez konieczności odnawiania subskrypcji.

-  Licencja hybrydowa pozwala na integrację serwerów Exchange On-Premises (lokalnych) z usługami Microsoft 365 (chmurowymi). Oznacza to, że firmy będą mogły korzystać z rozwiązań chmurowych, jednocześnie utrzymując część swoich zasobów na własnych serwerach.
