## Answer (community) — Microsoft Moderator

Hi, MKamal.    

I Have Exchange 2016 15.1 I need to be sure that all the CU updates, hotfixes, etc are installed and up to date    

Would you please check what is the detailed CU version of your server?    

You can check it in the Control Panel>Programs and Features.    

    

If you are not on the latest CU version (CU19), it is recommended to upgrade to CU19 first.    

As CU updates will also include previous fixes for for security and nonsecurity issues.    

    

In addition,you can learn about the information of latest or previous CU versions in this Microsoft document: Exchange Server build numbers and release dates     

If you are on CU19, it is recommended to install the the security update for Microsoft Exchange Server 2019, 2016, and 2013: March 2, 2021 (KB5000871)    

For detailed information on this security update, please refer to this link.    

The link FAQ for March 2021 Exchange Server Security Updates  also shared some FAQ and tips on installing this security update, please go through it to learn about the best practices before you install the security update.    

To check whether the security update is installed successfully, you can check it via "Control Panel>Programs and Features>View installed update".
