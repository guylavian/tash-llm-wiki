## Question

In connection to the disablement of email basic authentication, we are being asked these details:
Directory (tenant) ID
Application (client) ID
Secret ID Value
Secret Expiration Date (MM-DD-YYYY)
Are these applicable to an on-premise exchange mail server?

Hello Bernadette Embuido  

The details you mentioned appear to be associated with Azure Active Directory (AAD) and are used for authentication purposes. However, if you are using an on-premises Exchange mail server, you may not need to provide these details.
