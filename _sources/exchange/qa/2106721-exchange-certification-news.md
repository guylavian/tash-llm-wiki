What is the status for Exchange Certification that was retired last year?

Based on your description, the Exchange Certification that was retired last year has not been reintroduced. As of now, there are no dedicated Exchange Certification pathways available, and there are no plans for new certifications in this area. However, Microsoft recommends exploring the Microsoft 365 Certified: Administrator Expert certification, which covers a broad range of Microsoft 365 workloads, including Exchange Online.

This certification is designed for administrators who deploy and manage Microsoft 365 and perform tenant-level implementation and administration of cloud and hybrid environments. It includes skills such as deploying and managing a Microsoft 365 tenant, implementing and managing Microsoft Entra identity and access, managing security and threats using Microsoft Defender XDR, and managing compliance using Microsoft Purview.

If you're looking to renew your existing Microsoft certifications, you can do so for free by passing an online assessment on Microsoft Learn. For the latest updates on certifications and exams, it's a good idea to subscribe to the Microsoft Tech Community Blog.
