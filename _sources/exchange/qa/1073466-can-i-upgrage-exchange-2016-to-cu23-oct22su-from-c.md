Hi @Supanirun Roopkaew  ,    

A Security Update is what you will install on top of a Cumulative Update.     

Because the current version of your server is Exchange CU22, you must upgrade Exchange 2016 CU22 to CU23 before you apply this SU.    

For information about how to install Exchange SU, refer to this article: install-exchange-security-update
