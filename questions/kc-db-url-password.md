# Q: What does the KC_DB_URL_PASSWORD environment variable control?

## Answer

**`KC_DB_URL_PASSWORD` is not a valid Keycloak/RHBK environment variable.** The name appears to be a conflation of two separate settings:

- **`KC_DB_PASSWORD`** — the env-var form of `--db-password` / `db-password`. Sets the database user's password (`reference/keycloak/rhbk-26-2-containers.md:45` — `ENV KC_DB_PASSWORD=<DBPASSWORD>`).
- **`KC_DB_URL`** — the env-var form of `--db-url` / `db-url`. Sets the full JDBC URL (`reference/keycloak/rhbk-26-2-containers.md:43` — `ENV KC_DB_URL=<DBURL>`).

### The actual database env vars

Keycloak translates CLI options (`--kebab-case`) to environment variables as `KC_<UPPER_SNAKE_CASE>` (`reference/keycloak/rhbk-26-2-configuration.md:44-46`). The real database-related runtime env vars (`entities/database-configuration.md:36-39`) are:

| Env var | CLI option | Purpose |
|---|---|---|
| `KC_DB_PASSWORD` | `--db-password` | Database user password |
| `KC_DB_URL` | `--db-url` | Full JDBC URL |
| `KC_DB_URL_HOST` | `--db-url-host` | Hostname (for vendor-default JDBC URLs) |
| `KC_DB_URL_PORT` | `--db-url-port` | Port (for vendor-default JDBC URLs) |
| `KC_DB_URL_DATABASE` | `--db-url-database` | Database name (for vendor-default JDBC URLs) |
| `KC_DB_USERNAME` | `--db-username` | Database username |
| `KC_DB_SCHEMA` | `--db-schema` | Database schema name |

`KC_DB_URL_HOST` is the env var most commonly used in the config-source precedence examples (`reference/keycloak/rhbk-26-2-configuration.md:77` — `export KC_DB_URL_HOST=mykeycloakdb`).

### Recommended practice

Put database credentials in `conf/keycloak.conf` or a KeyStore vault rather than passing them on the command line, since CLI flags expose the password in the process table (`entities/database-configuration.md:42`, `(inferred)` — general secrets-handling guidance, not a verbatim corpus caveat).
