# How do Windows clients locate a suitable domain controller?

Windows clients locate a domain controller via the **DC Locator algorithm**, implemented by the **Netlogon service** through the `DsGetDcName` API.

### Step by step

1. **DNS SRV lookup.** Netlogon calls `DnsQuery` to resolve SRV records under the `_msdcs.<forest-root>` DNS zone. The primary query is `_ldap._tcp.<DnsDomainName>`. Capability-specific variants are also queried: `_gc._tcp.` for Global Catalog, `_kerberos._tcp.` for KDC, and `_ldap._tcp.<SiteName>._sites.<DnsDomainName>` for site-scoped location.

2. **UDP LDAP ping.** The client sends a UDP LDAP search datagram to each candidate DC. Available DCs respond; the first to respond wins.

3. **Site-affinity check.** The responding DC examines the client's IP subnet. If the DC is not in the client's optimal site, it returns the correct site name. The client then retries with a site-scoped DNS query. Non-optimal DC entries are flushed from cache after 15 minutes.

4. **Netlogon cache.** The discovered DC is cached by the Netlogon service, so subsequent short-lived operations reuse the same DC without rediscovery, ensuring a consistent directory view.

5. **NetBIOS fallback (legacy).** When DNS discovery fails or only a NetBIOS-style domain name is provided, the client attempts NetBIOS-based discovery via WINS or mailslot broadcasts. Beginning with Windows Server 2025, the `BlockNetBIOSDiscovery` Group Policy defaults to `TRUE`, disabling this fallback.

### NetBIOS-to-DNS name mapping

When a short NetBIOS-style domain name is provided, DC Locator tries to map it to a DNS name in this order: local cache, domains in the current forest, trust TLNs, admin-configured mappings (Windows Server 2025+), sign-in sessions. If no mapping is found, it falls back to NetBIOS discovery (if permitted).

### Observability (Windows Server 2025+)

Three perfmon counter sets: **DC Locator (Client)**, **DC Locator (DC)**, and **DC Locator (Netlogon)**. Key counters include `Requests: Failures/sec`, `DNS Query Failures/sec`, and `Cache: Hits/sec`.
