# Q: What is RHBK's default password hashing algorithm in 26.x, and how do I change it?

## Answer
- **Non-FIPS (the common case): `argon2`.** Argon2 became the default password
  hashing algorithm in RHBK **26.0** (winner of the 2015 Password Hashing
  Competition; far lower CPU than PBKDF2 at comparable strength). Default
  iterations `5`, parallelism capped to JVM-available cores.
- **FIPS deployments: `pbkdf2-sha512`** (default iterations `210,000`), because
  Argon2 isn't available in the FIPS crypto path — see [[fips-startup-bouncycastle]]
  for the "Invalid credentials" admin-login failure this mismatch causes.

Change the server-wide default with:
```sh
bin/kc.sh start --spi-password-hashing-provider-default=pbkdf2-sha512
```
Changing the algorithm does **not** re-hash existing passwords immediately — each
user's stored hash is upgraded the next time they log in (inferred from the
re-hash-on-login behavior). Per-realm strength rules live under
**Authentication → Policies**; see [[password-policies]].
