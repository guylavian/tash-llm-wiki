# Mapping RH-SSO 7.6 standalone.xml to RHBK kc.sh options

**Each `standalone.xml` subsystem maps to flat `kc.sh --option` parameters, with the runtime changing from JBoss EAP to Quarkus.**

The key change: RHBK replaces the JBoss EAP runtime with Quarkus, so `standalone.xml`, `jboss-cli`, and operating-mode scripts no longer apply. Configuration is now a flat set of `--key=value` options from four ordered sources (CLI > env var > config file > KeyStore). See [[server-config-migration]] and [[quarkus-config-migration]].

| `standalone.xml` / RH-SSO 7.6 concept | RHBK `kc.sh` option(s) |
|---|---|
| `KeycloakDS` datasource (connection URL, driver, pool, user/password) | `--db`, `--db-url-host`, `--db-url-port`, `--db-url-database`, `--db-schema`, `--db-pool-min-size`, `--db-pool-max-size`, `--db-username`, `--db-password` |
| HTTP/TLS (`<undertow>` / `<server>` keystore) | `--https-key-store-file`, `--https-key-store-password` (keystore) or `--https-certificate-file`, `--https-certificate-key-file` (PEM); http-relative-path=/auth to restore the old /auth prefix |
| Infinispan / cache subsystem (`<cache-container>`, JGroups) | Separate Infinispan config; exposed knobs like `--cache-embedded-realms-max-count`; default transport is `--jgroups-stack=jdbc-ping` |
| Hostname SPI (`frontendUrl`) | `--hostname` (mandatory in `start`), `--hostname-admin`, `--proxy-headers xforwarded` (or `forwarded`), `--hostname-strict=false` to disable enforcement |
| File truststore SPI | `--truststore-paths` (PEM or unencrypted PKCS12; JKS must be converted); `--tls-hostname-verifier WILDCARD` |
| Elytron Credential Store (vault) | `--vault keystore --vault-file ... --vault-pass ...` |
| JVM (`standalone.conf`) | `JAVA_OPTS` (full replace) or `JAVA_OPTS_APPEND` (append) |
| SPI provider XML blocks (`<spi><provider><property>`) | Flat `--spi-<spi-id>-<provider-id>-<property>=<value>` |
| Operating mode (standalone / standalone-ha / domain) | `kc.sh start --cache=local` (standalone) / `kc.sh start [--cache=ispn]` (HA); domain mode not supported |

See [[server-config-migration]] for the detailed mapping and [[database-auto-migration]] for schema migration behavior.
