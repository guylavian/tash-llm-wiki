# The four ordered configuration sources for RHBK

RHBK reads options from four configuration sources, applied in descending priority order (first = highest priority):

| Priority | Source | Format |
|---|---|---|
| 1 | Command-line parameter | `--<key-with-dashes>=<value>` |
| 2 | Environment variable | `KC_<KEY_WITH_UNDERSCORES>=<value>` |
| 3 | `conf/keycloak.conf` (or `--config-file=` file) | `<key-with-dashes>=<value>` |
| 4 | Java KeyStore config source | `kc.<key-with-dashes>` (value = password in KeyStore) |

If the same option is set in multiple sources, the highest-priority source always wins. For example, `--db-url=cliValue` overrides `KC_DB_URL`, which overrides `db-url=` in `keycloak.conf`, which overrides `kc.db-url` in the KeyStore.

The KeyStore is the recommended place for sensitive runtime options like `db-password` (`entities/config-sources-precedence.md:33-35`).
