# Creating a temporary admin user in RHBK for first start or recovery

**RHBK provides three methods to create a temporary admin account for first start or when admin access is lost.**

## Method 1: Startup flags (first start only)

Add to `kc.sh start` or `kc.sh start-dev`:

```sh
bin/kc.sh start --bootstrap-admin-username tmpadm --bootstrap-admin-password pass
```

Or via environment variables: `KC_BOOTSTRAP_ADMIN_USERNAME` / `KC_BOOTSTRAP_ADMIN_PASSWORD`.

This only works on the **first start** when the `master` realm does not exist yet. The account is always created in the `master` realm (kb:rhbk-26-4-bootstrap-admin-recovery §3.2).

## Method 2: Dedicated `bootstrap-admin` command (first start or recovery)

Stop all nodes, then:

```sh
bin/kc.sh bootstrap-admin user --username tmpadm --password:env PASS_VAR
```

For a service account (useful when OTP/advanced auth is enforced on the realm):

```sh
bin/kc.sh bootstrap-admin service --client-id tmpclient --client-secret:env SECRET_VAR
```

Passwordless/OTP recovery: create the service account, then authenticate with `kcadm.sh` to remove the blocking credential (kb:rhbk-26-4-bootstrap-admin-recovery §3.4).

Default username/client-id is `temp-admin`. Use `--no-prompt` to disable interactive prompts. If using an optimized image, pass `--optimized` to skip the build check (kb:rhbk-26-4-bootstrap-admin-recovery §3.3).

## Method 3: Operator (OpenShift)

Omit `spec.bootstrapAdmin` and the Operator auto-generates a Secret `<cr-name>-initial-admin` with username `temp-admin` and a random password. Fetch with:

```sh
oc get secret example-kc-initial-admin -o jsonpath='{.data.username}' | base64 --decode
oc get secret example-kc-initial-admin -o jsonpath='{.data.password}' | base64 --decode
```

Or set `spec.bootstrapAdmin` to name a Secret with `username`/`password` or `client-id`/`client-secret`. **If the master realm already exists, `spec.bootstrapAdmin` is ignored** — use Method 2 directly against a Pod instead ([[operator-initial-admin]]).

## Post-bootstrap

After gaining access, create a permanent admin account and remove the temporary one. The Admin Console shows a warning banner indicating the account is temporary (kb:rhbk-26-4-bootstrap-admin-recovery §3.1).
