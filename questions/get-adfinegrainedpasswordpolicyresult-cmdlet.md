# What does the `Get-ADFineGrainedPasswordPolicyResult` PowerShell cmdlet return?

**`Get-ADFineGrainedPasswordPolicyResult` does not exist** as a cmdlet in the Active Directory PowerShell module.

## Body

The cmdlet you're looking for likely does not exist under any name. The actual Active Directory module cmdlets for fine-grained password policies are listed in the ADAC documentation (`reference/active-directory/ad-ds-advanced-ad-ds-management-using-active-directory-administrative-center-level-200.md:237-247`):

- `Add-ADFineGrainedPasswordPolicySubject`
- **`Get-ADFineGrainedPasswordPolicy`** — returns `Microsoft.ActiveDirectory.Management.ADFineGrainedPasswordPolicy` object(s) representing the Password Settings Object (PSO) itself, with properties such as `Name`, `MinPasswordLength`, `Precedence`, `LockoutThreshold`, etc.
- **`Get-ADFineGrainedPasswordPolicySubject`** — returns the user and group objects that a given PSO applies to
- `New-ADFineGrainedPasswordPolicy`
- `Remove-ADFineGrainedPasswordPolicy`
- `Remove-ADFineGrainedPasswordPolicySubject`
- `Set-ADFineGrainedPasswordPolicy`

A closely related cmdlet that also exists in the module but was not listed in that source is **`Get-ADUserResultantPasswordPolicy`**, which returns the resolved/effective `ADFineGrainedPasswordPolicy` object for a specific user after precedence evaluation — likely closest to what "result" in the name suggests (inferred).
