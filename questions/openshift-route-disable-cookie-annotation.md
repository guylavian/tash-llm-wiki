# haproxy.router.openshift.io/disable-cookie does not exist

**The annotation `haproxy.router.openshift.io/disable-cookie` (hyphenated, singular) does not exist in the OpenShift corpus.**

The real annotation uses an underscore and the plural form: `haproxy.router.openshift.io/disable_cookies`.

## What it controls

When set to `'true'` or `'TRUE'` on a Route, it disables the use of cookies to track related connections. HAProxy then uses the configured balance algorithm (e.g. `random`, `source`, `roundrobin`, `leastconn`) to choose which backend serves each incoming HTTP request (`reference/openshift/networking-4-22-nw-configuring-routes.md:398`).

This is commonly needed on passthrough TLS routes where HAProxy cannot read cookies at the TCP level, so cookie-based stickiness has no effect and should be explicitly disabled (`questions/passthrough-roundrobin-login-loop.md:95-101`).

## Why the confusion

The OpenShift docs reference this annotation inconsistently — the annotation table at `networking-4-22-nw-configuring-routes.md:398` uses `disable_cookies` (underscore, plural), while surrounding prose paragraphs at lines 188 and 216 use `disable_cookie` (underscore, singular). Neither uses hyphens, so `disable-cookie` (hyphenated, singular) is not a valid form.
