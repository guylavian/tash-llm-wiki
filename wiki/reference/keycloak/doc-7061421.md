# Is it possible to account activation email can be configured per client in RHSSO ?

Is it possible to account activation email can be configured per client in RHSSO ?
Environment
- Red Hat Single Sign On
- 7.x
- Red Hat Build of Keyclaok
- 22.0
Issue
- Account activation email can only be configured per client in RHSSO/Keycloak ?
- In detail, Application A (client A in Keycloak) would like to have its own account activation email template
while Application B (client B in Keycloak) would like to have another email template. Application A and
Application B prefer to have different email contents on the account activation.
Resolution
- Unfortunately it is not possible but for each realm it is possible.
root realm --+---realm A --- client A
|
+---realm B --- client B
However, you can implement a custom SPI but it is not supported. It is recommended to purchase GPS support consultation with additional costs.
Root Cause
We do not have direct documentation to change the custom SPI for the email template, customers need to develop their own and run the implementation module in RHSSO. Other SPIs are available in the Keycloak community upstream release documentation (such as Extending the Server, Authentication SPI, Action Token SPI, Event Listener SPI), but they are not supported yet in the current RH-SSO releases.
SPIs that are not supported may have undocumented API and behavior changes between versions. Customers can still develop, deploy and run a custom spi implementation module in RH-SSO, but without Red Hat support on such custom code. However, the RH-SSO instance running such customized code will still be supported by Red Hat. If something wrong happens, Red Hat Support may ask those customers to temporarily remove the custom module to prove that an issue is not relevant to the custom spi implemented module.
Note: Red Hat always highly recommend customers to engage with Red Hat Consulting service team for any custom
spi implementation and custom extensions in RH-SSO.
