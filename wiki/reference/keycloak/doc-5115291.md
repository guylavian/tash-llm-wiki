# Support of Red Hat Middleware products and components on Red Hat OpenShift

Support of Red Hat Middleware products and components on Red Hat OpenShift
Red Hat Middleware products are supported on Red Hat OpenShift 3.x and 4.x under the following terms.
Existing middleware life cycles apply to deployments in OpenShift. This article does not modify the life cycle phases and dates defined in the Product Update and Support Policy. Existing middleware Supported Configurations pages may have more details. The individual product supported configuration pages supercede this article.
OpenShift 4.x Versions
Middleware products are supported on all OpenShift versions in Full or Maintenance support in the Stable and EUS
channels of OpenShift.
Due to breaking API changes in some of the OpenShift releases a minor/micro may not be compatible with all versions of OpenShift and a new minor/micro will be provided to resolve the compatibility issue. Please see your product's Supported Configurations for detailed information.
Refer to the exclusions section of this document for additional product specific details.
OpenShift 3.x Versions
Middleware products are supported in OpenShift 3 in the 3.11 version only. Older versions of OpenShift 3.x are not supported. OpenShift 3.11 moved to ELS as of June 30, 2022 and will remain in ELS until June 30, 2024. As such, an ELS entitlement is required for continued support during this period.
Refer to the exclusions section of this document for additional product specific details.
Support on OpenShift Kubernetes Engine
Red Hat Middleware products are supported on OpenShift Kubernetes Engine (OKE), but OKE does not provide entitlements to any of the middleware products that are included in the OpenShift Container Platform (OCP) entitlement, like Single Sign-On, Red Hat build of Keycloak, or Quarkus. OKE offers a subset of the features that OpenShift Container Platform offers, excluding features like Service Mesh, builds, Serverless, CI/CD pipelines, and more. The limited features of OKE constrain the availability and support of some features available from the Red Hat Middleware products on the OpenShift Container Platform. We recommend users deploy middleware applications on OCP for the best user experience.
Refer to the Self-managed Red Hat OpenShift sizing and subscription guide for the Red Hat OpenShift Kubernetes Engine Subscription components, which do not include any of the Red Hat Middleware products or components.
Hardware Architectures
A number of Red Hat middleware products are available and supported in OpenShift 4 clusters on IBM Z. Those products are EAP 7.3 and later, SSO 7.4 and later 7.x releases, Red Hat build of Apache Camel 4.4 and later, Data Grid 8.x, JWS 5, Quarkus, Spring Boot, Node.js, and Vert.x.

Exclusions
| Middleware Product | Exclusion or Limitation |
|---|---|
| The Red Hat Data Grid operator | not supported on OpenShift 3.11. Data Grid 8 is only installed via operator, and is not supported on OpenShift 3.x |
| The Red Hat JBoss EAP operator | not supported on OpenShift 3.11 |
| Red Hat JBoss EAP XP | not supported on OpenShift 3.11 |
| Red Hat JBoss Web Server 3.x | not supported on OpenShift 4.x, supported on OpenShift 3.11 ONLY |
| The Core Services Collection | not supported on OpenShift, with the exception of Red Hat Single Sign-On, which is included in the base OpenShift entitlement |
| Red Hat build of Debezium | not supported on OpenShift 3.x |
| Red Hat build of Apache Camel | not supported on OpenShift 3.x |
| Camel K | not supported on OpenShift 3.x |
| Camel Kafka Connector | not supported on OpenShift 3.x |
| Red Hat build of Apicurio Registry | not supported on OpenShift 3.x |
| Red Hat build of Node.js | support policy is in effect for the duration of the application stream (~ 2 years for Node.js) on supported versions of OpenShift |
| Red Hat AMQ Broker | not supported on OpenShift 3.x |
| Red Hat AMQ Streams | not supported on OpenShift 3.x |
