# Configure "Users in Role" tab to be Read-Only mode in RHSSO/Keycloak console

Configure "Users in Role" tab to be Read-Only mode in RHSSO/Keycloak console
Environment
- Red Hat Build of Keycloak (RHBK)
- 22.0
- Red Hat Single Sign On(RHSSO)
- 7.6
Issue
- How to configure "Users in Role" tab in Read-Only mode ?
Resolution
- The bug is fixed in RHBK 22, recommended to use the same.
Root Cause
It is a bug in RHSSO 7.6 version. When tested in the latest RHBK 22 version it is working as expected.
