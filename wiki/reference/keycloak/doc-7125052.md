# Unexpected behavior in RHBK26 admin console realm selection

Unexpected behavior in RHBK26 admin console realm selection
Environment
- Red Hat build of Keycloak
- 26.0.9
Issue
After logging into the RHBK26 admin console as a user with access to a specific realm (ehrss_admin), unauthorized realms (e.g., "master") are visible in the realm selection dropdown. Attempting to switch to an unauthorized realm results in an error page. This behavior differs from RHBK26 version 2.0, where users could not see realms they were not authorized to access.
Root Cause
The behavior appears to be a defect in the current version of RHBK26. A SSOSUP has been created to validate and investigate the issue further.
Diagnostic Steps
Steps to reproduce:
1.Log in to the RHBK26 admin console as a user with access to a specific realm (e.g., test_admin with access to "test").
2.Observe the available realms in the selection box.
3.Attempt to switch to an unauthorized realm (e.g., "master").
4.Note the error page displayed.
5. Switch back to the authorized realm and click "Press here to refresh and continue".
