# Automatically deactivate users after certain period of inactivity in Red Hat build of Keycloak

Automatically deactivate users after certain period of inactivity in Red Hat build of Keycloak
Environment
- Red Hat build of Keycloak
- 26.x
Issue
- Is there a way to automatically disable users after a period of inactivity. Eg. if the user has not logged in to Keycloak, or any of the associated apps in 1 year.
Resolution
-
This RFE is in progress, and it will be included in the first version of the feature. However, the current plan is that the feature will only be available from the Admin UI in Keycloak 27.
-
Red Hat build of Keycloak lacks built-in functionality for inactivity-based account deactivation at the user level. Features like SSO Session Idle and Brute Force Detection handle short-term session timeouts or failed login attempts, but not extended login inactivity.
