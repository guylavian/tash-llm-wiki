# When will the table 'USERNAME_LOGIN_FAILURE' populated with data ?

When will the table 'USERNAME_LOGIN_FAILURE' populated with data ?
Environment
- Red Hat Build of Keycloak(RHBK)
- 24.0.8
Issue
- Interested to use 'USERNAME_LOGIN_FAILURE' table and want to know on which situation (+ configuration) this table will populated with data.
Resolution
The table USERNAME_LOGIN_FAILURE was used a very long time ago when the Keycloak community had support to store sessions in Mongo database and JPA.Since RH-SSO is based in the Keycloak community project, the same has not been removed yet.
There was a rework to remove the unused tables but for some reason, this table has not been dropped. In the current RH-SSO version, this table exists but it is not used.
