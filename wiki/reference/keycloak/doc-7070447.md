# RHBK REST Admin API to create and add user attributes

RHBK REST Admin API to create and add user attributes
Environment
- Red Hat Build of Keycloak
- 22.0.10
Issue
- Is there an API in RHBK to add user attributes instead of replacing them?
- How do I PUT JSON to register multiple attributes at once?
Resolution
Below are the steps to add and replace user attributes in RHBK using Admin REST API:
Step 1.
Retrieve the user by passing the userID in the API url:
curl -X GET http://localhost:8080/admin/realms/master/users/6895d199-dff4-4f2c-81b8-03f74182a1c3 -H "Authorization: Bearer $TKN" -H "Content-Type: application/json" -v | jq
Step2.
Run the following PUT curl API call for the above userID and pass user attributes in JSON body you wish to create. In below example 3 attributes are created i.e. phone, age and location:
curl -X PUT "http://localhost:8080/admin/realms/master/users/6895d199-dff4-4f2c-81b8-03f74182a1c3" \
-H "Authorization: Bearer $TKN" \
-H "Content-Type: application/json" \
-d '{
"attributes": {
"phone": ["123-456-7890"],
"age": ["30"],
"location": ["New York"]
}
}'
Step3.
Once the API call from step 2 is successfully executed, run the API call from step 1 to verify user attributes are created:
curl GET http://localhost:8080/admin/realms/master/users/6895d199-dff4-4f2c-81b8-03f74182a1c3 -H "Authorization: Bearer $TKN" -H "Content-Type: application/json" -v | jq

- To add more attributes you would have to retrieve the existing ones and merge the new attributes with old ones and then update the user with the combined set of attributes (old + new). For example in the following API call 3 new attributes are added with 3 old attributes created above:
curl -X PUT "http://localhost:8080/admin/realms/master/users/6895d199-dff4-4f2c-81b8-03f74182a1c3" \
-H "Authorization: Bearer $TKN" \
-H "Content-Type: application/json" \
-d '{
"attributes": {
"phone": ["123-456-7890"],
"age": ["30"],
"location": ["New York"],
"Country": ["USA"],
"Zip": ["12456"],
"Status": ["Pending"],
}
}'
- To replace user attributes, run the Admin REST API curl command and add only those attributes you want. User attributes that you don't mention in the API JSON body will not be created.
