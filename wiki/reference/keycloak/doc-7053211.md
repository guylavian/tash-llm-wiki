# Query regarding  resource name and UID in obtaining RPT

Query regarding resource name and UID in obtaining RPT
Environment
- Red Hat Single Sign On
- 7.x
- Red Hat Build Keycloak(RHBK)
- 22.x
Issue
- Does resource name and resource UID supported in the API for obtaining permissions ?
- Could you please clarify what "RESOURCE_ID#SCOPE_ID" refers to? Specifically, does it refer to a UUID or the
name of the resource ?
Resolution
- Basically RESOURCE_ID#SCOPE_ID is a combination of an actual resource and actual scope. Both of the following command will work with resource name or UID - since uniqueness is guaranteed for both the parameters and index for both are created. Take this following resource as an example : name = 'example_resource' and UID = '569f67de-36e6-ac54-e52085109818'
curl -X POST \
http://${host}:${port}/auth/realms/${realm}/protocol/openid-connect/token \
...
--data "permission=example_resource'#Scope A" \
curl -X POST \
http://${host}:${port}/auth/realms/${realm}/protocol/openid-connect/token \
...
--data "permission=569f67de-36e6-ac54-e52085109818#Scope A" \
Root Cause
- The parameter permission_resource_format is not documented in RHSSO 7.6 but in RHBK 22.x added as below:
permission_resource_format
This parameter is optional. A string representing a format indicating the resource in the permission parameter. Possible values are id and uri. id indicates the format is RESOURCE_ID. uri indicates the format is URI. If not specified, the default is id.
