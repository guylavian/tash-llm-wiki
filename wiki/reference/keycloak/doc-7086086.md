# Does deleting a group in RHBK/Keycloak should also reflect/sync in LDAP ?

Does deleting a group in RHBK/Keycloak should also reflect/sync in LDAP ?
Environment
- Red Hat Build of Keycloak(RHBK)
- 24.x
- 22.x
- Red Hat Single Sign On(RHSSO)
- 7.x
Issue
- Configure periodic sync from Keycloak to LDAP.
- Changes done in Keycloak/RHBK are automatically sync to LDAP
- Deleting, or moving groups in Keycloak is not reflected in LDAP even
manually triggers a sync.
Resolution
-
Raised the request of future enhancement as a github issue
If accepted, will be implemented in the future releases of RHBK.During the test deletion is not propagated keycloak to ldap, that indicates in keycloak console "Sync..." button
in group-ldap-mapper made for just group IMPORT.
Workaround
Need to remove a group from both of Keycloak and LDAP manually.
