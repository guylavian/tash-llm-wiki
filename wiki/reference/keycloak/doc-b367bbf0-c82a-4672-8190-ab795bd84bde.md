# Home Realm Discovery

Home Realm Discovery
We are planning to use Red Hat build of Keycloak and I wanted to ask about support for Home Realm Discovery (HRD).
At the moment, when a user signs in, they must first select their IdP on the login screen, and then Keycloak redirects them to the relevant IdP login page.
What we’d like instead is a smoother experience: the user enters their email address on the Keycloak login screen, and Keycloak automatically detects the user’s domain and redirects them to the correct IdP, without requiring them to manually choose it first.
Could you confirm if Red Hat’s Keycloak distribution supports this functionality, or if there is a recommended approach/plugin to achieve it?
