# Red Hat Runtimes for IBM Cloud Pak for Applications Customers

Red Hat Runtimes for IBM Cloud Pak for Applications Customers
Customers of IBM's Cloud Pak for Applications product have access to the full portfolio of Red Hat's Runtimes and associated components. This article details the entitlements and resources available to IBM customers.
About Red Hat Runtimes
The Red Hat portfolio of middleware products helps you create a unified environment for application development, delivery, integration, and automation. It is comprised of comprehensive frameworks, integration solutions, process automation, runtimes, and programming languages. A sub-set of this portfolio is the Red Hat Runtimes, a set of products, components, and services.
