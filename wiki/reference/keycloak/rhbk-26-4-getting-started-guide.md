# Getting Started Guide - Red Hat build of Keycloak 26.4 Getting Started Guide

Getting Started Guide
Red Hat build of Keycloak 26.4
Abstract
This guide helps you practice using Red Hat build of Keycloak 26.4 to evaluate it before you use it in a production environment. It includes instructions for installing and running the Red Hat build of Keycloak server in development mode, creating realms and accounts for managing users and applications, and securing a Single Page Application (SPA)
