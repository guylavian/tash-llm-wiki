# The "frame-ancestors" setting is missing in the response header in RHBK

The "frame-ancestors" setting is missing in the response header in RHBK
Environment
- Red Hat Build Keycloak(RHBK)
- 22.x
- 24.x
- Red Hat Single Sign On(RHSSO)
- 7.x
Issue
- Frame-ancestors 'self' is missing in header section below
Request URL:
http://localhost:8080/realms/master/protocol/openid-connect/3p-cookies/step1.html
Request Method:
GET
Status Code:
200 OK
Remote Address:
[::1]:8080
Referrer Policy:
no-referrer
Cache-Control:
no-cache, must-revalidate, no-transform, no-store
Content-Length:
28718
Content-Security-Policy:
frame-src 'self'; object-src 'none'; ----------------> frame-ancestors 'self' is missing
Content-Type:
text/html;charset=utf-8
Referrer-Policy:
no-referrer
Resolution
-
It is static html resources always missing in the header output, this is expected behavior.
To workaround the behavior add configuration in undertow layer
and for RHBK
