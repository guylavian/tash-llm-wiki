# When will be Keycloak be supported by Red Hat?

When will be Keycloak be supported by Red Hat?
Environment
- Red Hat Single Sign-On (RH-SSO)
- All versions
- Red Hat build of Keycloak
- All versions
Issue
- We would like to use Keycloak project in our application.
- When will Keycloak be supported by Red Hat?
Resolution
Red Hat does not provide commercial support for community open source projects directly. Instead, Red Hat derives product offerings from community projects which are branded and maintained separately.
The Red Hat product derived from the community Keycloak project is called Red Hat Single Sign-On (RH-SSO). Each release of RH-SSO derives from a specific Keycloak community version. Refer to the Red Hat Single Sign-On (RH-SSO) Roadmap table that describes this relationship.
The newest, quarkus based release is called Red Hat build of Keycloak and it is derived of a specific community Keycloak version. Refer to Red Hat build of Keycloak Release and Maintenance schedule
