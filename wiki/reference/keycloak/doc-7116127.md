# RHBK/RH-SSO missing Insights-Java-Client Support for Hybrid Console Integration

Issue
- Why RHBK and RH-SSO Aren’t Supported in Red Hat Hybrid Console and How to Fix It ?
- Cannot See RHBK/RH-SSO in Hybrid Console?
Resolution
-
RHBK/RHSSO do not support insights-java-client, which means RHBK cannot be displayed in the RH Hybrid Console.
-
If this functionality is required in the future, the following prerequisites must be met:
- RHBK/RH-SSO must be registerable in subscription-manager (necessary for insights-java-client authentication

-
This would require a Request for Enhancement (RFE) to implement support.
Root Cause
To integrate with the Hybrid Console, the insights-java-client must authenticate and transmit data to Red Hat Insights (Red Hat’s telemetry and analytics service).
However, this authentication process requires the product (RHBK/RH-SSO) to be registered in subscription-manager—Red Hat’s system for managing entitlements and subscriptions.
The root cause of the integration failure is that RHBK/RH-SSO currently cannot be registered in subscription-manager, preventing the necessary authentication and blocking data transmission to Red Hat Insights.
