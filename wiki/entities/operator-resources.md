# `resources`

**The `spec.resources` field on the [[keycloak-cr]] — compute requests/limits for
the RHBK container, set independently for the server and the realm-import Job.**

```yaml
spec:
  resources:
    requests:
      cpu: 1200m
      memory: 896Mi
    limits:
      cpu: 6
      memory: 3Gi
```

## Defaults & fallback

- When unspecified: requests memory **1700MiB**, limits memory **2GiB** (chosen
  from RHBK memory-management analysis).
- The **Realm Import Job** ([[keycloak-realm-import]]) can set its own `resources`;
  if it doesn't, it falls back to the Keycloak CR's values, then to the defaults.
- The container sizes the JVM heap **relatively** (via JVM options) from these
  limits rather than using fixed values.

## Contradictions / caveats

- Consistent across 26.0–26.6.
