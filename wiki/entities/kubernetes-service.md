# Kubernetes Service

**A Service is a stable endpoint in front of a changing set of pods selected by label.** Clients talk to the Service's ClusterIP / DNS name; kube-proxy load-balances to the **ready** pod endpoints, so pod-IP churn is invisible to callers.

## Types
- **ClusterIP** (default) — internal-only virtual IP.
- **NodePort** — also reachable on every node IP at a static port.
- **LoadBalancer** — provisions an external cloud load balancer.
- **ExternalName** — a CNAME alias to an external DNS name (no proxying).

## The endpoint set
- Only pods passing their **readiness** probe (see [[kubernetes-pod]]) are in the endpoint set. A Service with a typo'd selector — or whose pods never become ready — has **no endpoints**, and anything in front of it (an [[openshift-route]]) returns 503.
- CoreDNS gives every Service `*.<namespace>.svc.cluster.local`; headless Services expose per-pod records (used by StatefulSets).
