# LDAP Mappers

**Components attached to an LDAP provider that map LDAP data (attributes, groups,
roles) onto RHBK user attributes, group memberships, and role mappings.**

## Types (common)
- **user-attribute-ldap-mapper** — maps a single LDAP attribute to an RHBK user
  attribute.
- **role-ldap-mapper** — maps LDAP roles (usually groups in a branch of the tree)
  to realm roles or a specified client's client roles. Multiple role mappers can
  attach to the same provider.
- **group-ldap-mapper** — maps LDAP groups to RHBK groups.
- Vendor presets (e.g. MSAD) add account-control / password mappers automatically.

## Configuring via kcadm
Mappers are `components` with `providerType=org.keycloak.storage.ldap.mappers...`:

```sh
kcadm.sh create components -r demorealm \
  -s name=user-attribute-ldap-mapper \
  -s providerId=user-attribute-ldap-mapper \
  -s providerType=org.keycloak.storage.ldap.mappers.LDAPStorageMapper \
  -s parentId=<ldap-provider-component-id> \
  -s 'config."ldap.attribute"=["mobile"]' \
  -s 'config."user.model.attribute"=["mobile"]'
```

## Caveats
- A role/group mapper's sync direction and "mode" interact with the provider's
  [[ldap-storage-mode]] (import vs. on-demand).
- Documented in `Chapter 4. Using external storage` and `Chapter 18. Admin CLI`
  (Server Administration Guide).
