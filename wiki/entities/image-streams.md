# ImageStreams

**An ImageStream is an abstraction over container images — it contains no image data, only a virtual view of related images, similar to a repository — that decouples what an app references from where the actual image lives.**

## Why it exists
Source images can live in OpenShift's own **internal (integrated) registry**, an external registry (`registry.redhat.io`, `quay.io`), or another ImageStream in the cluster. Objects that consume an image — a `BuildConfig` or a `DeploymentConfig` — point at an **ImageStreamTag**, never at the repository directly; at build/deploy time OpenShift resolves the tag to the exact image ID it currently references. Benefits: tag/rollback without re-pushing, build/deploy triggers on new image push, periodic re-import of an external tag, and fine-grained access control per stream. Image stream metadata (not the image bytes) is stored in etcd.

## Image stream tags
An **ImageStreamTag** (`istag`) is a named pointer into an ImageStream's history — it keeps a stack of every image it has ever pointed to, so a rollback is just pointing the tag back at the prior SHA. Two flavors:
- **Permanent tags** — a stable, human-chosen version reference.
- **Tracking tags** — follow another tag, like a symlink (e.g. OpenShift's own `latest` istag tracks a specific release line, not literally "the newest image" the way Docker's `latest` tag does — an important distinction from the Docker convention of the same name).

## Change triggers → the build/deploy chain
An **ImageStream change trigger** lets a `BuildConfig` or `DeploymentConfig` watch a specific ImageStreamTag and react automatically when it's updated — this is the mechanism that chains BuildConfig → ImageStream → rollout: a build pushes its output to an ImageStreamTag, and any DeploymentConfig with an `ImageChange` trigger on that same tag starts a new deployment automatically. If the consuming object's tag reference isn't updated, the deployment/build keeps using the old, known-good image even if the underlying registry image changes underneath it.
