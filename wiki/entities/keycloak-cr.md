# Keycloak CR (`k8s.keycloak.org/v2alpha1`)

**The `Keycloak` custom resource — the declarative spec the RHBK Operator
reconciles into a StatefulSet, Service, and optional Ingress.**

## Field map (selected)

The CR structure mirrors RHBK's own configuration: a server option `https-port`
maps to the CR field `httpsPort`, etc.

- `spec.instances` — replica count for the server StatefulSet.
- `spec.db` — `vendor`, `host`, `database`, `port`, `schema`, pool sizing
  (`poolInitialSize`/`poolMinSize`/`poolMaxSize`), and `usernameSecret` /
  `passwordSecret` Secret references. The Operator does **not** manage the DB.
- `spec.http` — `httpEnabled`, `httpPort`, `httpsPort`, and `tlsSecret`
  (a `kubernetes.io/tls` Secret).
- `spec.hostname` — `hostname`, `admin`, `strict`, `backchannelDynamic`.
- `spec.proxy.headers` — `forwarded` | `xforwarded` | `forwarded|xforwarded`.
- `spec.ingress` — `enabled`, `className` (see [[operator-ingress]]).
- `spec.features.enabled` / `spec.features.disabled` — toggle server features.
- `spec.transaction.xaEnabled`.
- `spec.image` / `spec.startOptimized` — custom images ([[custom-keycloak-image]]).
- `spec.additionalOptions` — escape hatch ([[additional-options]]).
- `spec.truststores` — extra trusted certs ([[keycloak-truststores]]).
- `spec.resources` — requests/limits ([[operator-resources]]).
- `spec.scheduling` — affinity/tolerations/spread ([[operator-scheduling]]).
- `spec.httpManagement.port` — management interface port.
- `spec.bootstrapAdmin` — initial admin user/service account ([[operator-initial-admin]]).
- `spec.update` — rolling vs recreate ([[operator-rolling-updates]]).
- `spec.unsupported.podTemplate` — raw Pod override, Tech Preview ([[operator-pod-template]]).

## Status conditions

`oc get keycloaks/<name> -o go-template='{{range .status.conditions}}...'`
exposes `Ready`, `HasErrors`, `RollingUpdate`, and `RecreateUpdateUsed`.

## Contradictions / caveats

- `apiVersion` is `v2alpha1` across 26.0–26.6, but the **set of fields grows by
  version**. Newer CRDs are generally backward compatible; older Operators reject
  CRs that use new fields with a deserialization error. Keep Operator and CRD
  versions aligned (see [[operator-olm-install]] on shared cluster-wide CRDs).
- The authoritative field list is the bundled Keycloak CRD, not this page.
