# Q: Should I enable "Import Users" for my LDAP provider?

## Answer
It depends on directory size and which features you need:

- **Turn Import ON** (default) if you want full user listing/search in the admin
  console, want other RHBK-local data to attach to users, and the directory is a
  manageable size. RHBK keeps a synchronized local copy.
- **Turn Import OFF** if the directory is very large or you want to avoid keeping
  a duplicated copy. Users are read from LDAP on demand, at the cost of some
  query/listing capability.

Pair the choice with the right **edit mode** (`READ_ONLY` / `WRITABLE` /
`UNSYNCED`) — see [[ldap-storage-mode]]. Note `UNSYNCED` with Import ON lets the
local copy drift from LDAP.
