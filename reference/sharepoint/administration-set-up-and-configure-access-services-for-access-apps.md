# Set up and configure Access Services for Access apps in SharePoint Server 2013

**APPLIES TO:** 2013 2016 2019 Subscription Edition SharePoint in Microsoft 365

To install, set up, and provision Access apps for SharePoint in Access Services in SharePoint Server 2016 or 2019, perform the following steps:

Install and configure SQL Server 2016 Enterprise software, because an Access app stores its data in a separate SQL Server back-end database.

Configure SharePoint 2016/2019 for apps for SharePoint, because an Access app is an app for SharePoint.

Configure Access Services for Access apps so that Access Services can successfully run Access apps.

Create a dedicated SharePoint site collection for Access apps, because each Access app requires its own subsite.

For information about how to set up and configure Access Services for Access apps, see the following white paper:

- White Paper: Access Services Setup for an On-Premise Installation of SharePoint 2016 and 2019

NOTE: For Access Services for SharePoint 2013, please see - White Paper: Office 2013--Access Services Setup for an On-Premises Installation
