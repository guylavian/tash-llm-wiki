# How to create resource based permissions using RestAPI ?

How to create resource based permissions using RestAPI ?
Environment
- Red Hat Build of Keycloak(RHBK)
- 22.x
- 24.x
- Red Hat Single Sign On(RHSSO)
- 7.x
Issue
- How to make resources based permissions/aggregate policies using
RestAPIs ? - To make below resource with AdiminAPI.
Resources
Resources Based Permissions
Aggregate Policies
Resolution
-
If the authentication elements are created by the console there are endpoints to create them via REST or kcadm. Start the developer tools in the chrome or firefox browser do the operations in the console and check what endpoints and what data is sent/received by the console. Just need to do the same via REST or kcadm.
- Create a resource in a client:
curl 'http://localhost:8080/admin/realms/test/clients/aadd0aac-2461-4b07-980d-e4c30c710d72/authz/resource-server/resource' ... --data-raw '{"name":"resource","displayName":"resource","type":"","scopes":[],"example_uri":"","ownerManagedAccess":false,"uris":["http://lululu.com",""],"attributes":{}}'
- Create a resource-based permission:
curl 'http://localhost:8080/admin/realms/test/clients/aadd0aac-2461-4b07-980d-e4c30c710d72/authz/resource-server/permission/resource' ... --data-raw '{"resources":["86481c25-10ca-44b2-ab03-96ea7f699f75"],"policies":["2548d89f-171b-40bd-b717-3e10966e45b8"],"name":"resource-based-permission","description":"","decisionStrategy":"UNANIMOUS"}'
- Create an aggregate policy:
curl 'http://localhost:8080/admin/realms/test/clients/aadd0aac-2461-4b07-980d-e4c30c710d72/authz/resource-server/policy/aggregate' ... --data-raw '{"policies":["2548d89f-171b-40bd-b717-3e10966e45b8"],"name":"Aggregate policy","description":"","decisionStrategy":"UNANIMOUS","logic":"POSITIVE"}'
