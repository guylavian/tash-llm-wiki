# Monitoring {sandboxed-containers-first}

[id="monitoring-sandboxed-containers"]
= Monitoring {sandboxed-containers-first}

[role="_abstract"]

You can use the OpenShift Container Platform web console to monitor metrics related to the health status of your sandboxed workloads and nodes.

{sandboxed-containers-first} has a pre-configured dashboard available in the web console, and administrators can also access and query raw metrics through Prometheus.

[role="_additional-resources"]
.Additional resources
* For more information about creating PromQL queries to view metrics, see Querying metrics.
