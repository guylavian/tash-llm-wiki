# Installing a cluster on vSphere using the Assisted Installer

[id="installing-vsphere-assisted-installer"]
= Installing a cluster on vSphere using the Assisted Installer

You can install OpenShift Container Platform on on-premise hardware or on-premise VMs by using the {ai-full}. Installing OpenShift Container Platform by using the {ai-full} supports `x86_64`, `AArch64`, `ppc64le`, and `s390x` CPU architectures.

The {ai-full} is a user-friendly installation solution offered on the Red{nbsp}Hat Hybrid Cloud Console.
